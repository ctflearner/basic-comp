Practice Task 1: Shortcut Drill

Objective: Practise every essential keyboard shortcut until you can use each one confidently.
Difficulty: Beginner
Time: 20 minutes

Instructions

  1. Open Notepad (press the Windows key, type "Notepad," press Enter).
  2. At the top of the file, type: "Keyboard Shortcut Practice"
  3. Press Enter twice to leave a blank line.
  4. Now practise each shortcut below. After trying each one, type what it does on a new line in Notepad.

Work through this list:

a. Press Ctrl+A -- what happened? Type your answer on the next line.
b. Type a new sentence: "This is my practice text for shortcuts."
c. Select all the text with Ctrl+A.
d. Press Ctrl+C to copy.
e. Press End to move to the end of the line, then Enter for a new line.
f. Press Ctrl+V to paste. Type: "Ctrl+V pastes copied text."
g. Type a new line: "I will now cut this line."
h. Select that line (click at the start, hold Shift, click at the end).
i. Press Ctrl+X to cut. The line disappears. Type: "Ctrl+X cuts (removes) selected text."
j. Press Ctrl+V to paste the cut text back. Type: "The cut text is back."
k. Press Ctrl+Z three times. Notice how each press undoes one action. Type: "Ctrl+Z undoes actions."
l. Press Ctrl+Y twice. Notice how it redoes what you just undid. Type: "Ctrl+Y redoes undone actions."
m. Press Ctrl+S. A Save dialog appears. Save the file to Documents as "Shortcut Practice.txt."
n. Press Ctrl+F. A find bar appears. Type "practice" and press Enter. It finds and highlights the word. Close the find bar with Esc.
o. Press Ctrl+P. A print dialog appears. Click Cancel (unless you want to print). Type: "Ctrl+P opens print."

  1. Now press Ctrl+S again to save everything you typed.
  2. Close Notepad with Alt+F4.

Expected Result

You have a text file saved in Documents called "Shortcut Practice.txt" containing notes on what each shortcut does. You used every major editing shortcut at least once.

Bonus Challenge

Repeat this exercise tomorrow without looking at the instructions. See how many shortcuts you can remember from memory.

Practice Task 2: Copy, Paste, and Save Workflow

Objective: Practise a complete real-world workflow using keyboard shortcuts only.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Open Notepad (Windows key, type "Notepad," Enter).
  2. Type the following paragraph:
My name is [your name]. I am learning digital skills. Today I practised keyboard shortcuts. My goal is to type faster and work more efficiently on the computer.
  1. Select all text: Press Ctrl+A (everything turns blue/highlighted).
  2. Copy: Press Ctrl+C.
  3. Open a second Notepad window: Press the Windows key, type "Notepad," press Enter.
  4. You now have two Notepad windows open.
  5. In the new (empty) window, paste: Press Ctrl+V. Your paragraph appears.
  6. Save this file: Press Ctrl+S. Save it to Documents as "Practice Copy.txt."
  7. Switch back to the first Notepad: Press Alt+Tab. You should see the original Notepad.
  8. Add a new line at the bottom: "This is the original file."
  9. Save: Press Ctrl+S. Save this one as "Practice Original.txt."
  10. Close both windows with Alt+F4 (press it twice -- once for each window).
  11. Open File Explorer with Win+E and navigate to Documents.
  12. Verify both files are there: "Practice Original.txt" and "Practice Copy.txt."

Expected Result

Two text files exist in your Documents folder. The original has your paragraph plus an extra line. The copy has just the paragraph. You completed the entire task using only keyboard shortcuts (no mouse menus for copy/paste).

Bonus Challenge

Open both files, select all text in each, and paste both into a third new file called "Combined.txt." Use only keyboard shortcuts.

Practice Task 3: Take Three Screenshots

Objective: Practise taking screenshots using Win+Shift+S and saving them.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. First, create a folder to save your screenshots:
    a. Open File Explorer (Win+E).
    b. Go to Pictures.
    c. Create a new folder called Screenshots (right-click, New, Folder, type "Screenshots," Enter).

  2. Screenshot 1: Your desktop
    a. Close or minimise all windows so you can see your desktop.
    b. Press Win+Shift+S. The screen dims and a toolbar appears at the top.
    c. Click "Rectangular Snip" (the first icon, a rectangle -- it may already be selected).
    d. Click and drag to draw a rectangle around an area of your desktop. Release the mouse button.
    e. A notification appears in the bottom-right corner. Click on it.
    f. The Snipping Tool opens with your screenshot. Click File then Save As (or press Ctrl+S).
    g. Navigate to Pictures then Screenshots.
    h. Name the file "Desktop Screenshot" and click Save.

  3. Screenshot 2: An open app
    a. Open the Calculator (Windows key, type "Calculator," Enter).
    b. Press Win+Shift+S.
    c. Draw a rectangle around just the Calculator window.
    d. Click the notification, then save to your Screenshots folder as "Calculator Screenshot."

  4. Screenshot 3: A portion of a web page
    a. Open your web browser and go to any website.
    b. Press Win+Shift+S.
    c. Draw a rectangle around an interesting part of the web page.
    d. Save as "Webpage Screenshot" in your Screenshots folder.

  5. Open your Screenshots folder and verify all three images are there.

Expected Result

Three screenshot image files saved in Pictures/Screenshots. Each one captures a different subject. You are now comfortable taking screenshots whenever you need to save something from your screen.

Bonus Challenge

Try the "Window Snip" option (second icon in the toolbar after pressing Win+Shift+S). Click on any window to capture just that window perfectly. Also try "Full Screen Snip" to capture everything.

Practice Task 4: Switch Between Apps Like a Pro

Objective: Practise using Alt+Tab and Win+D to navigate between multiple open applications.
Difficulty: Beginner
Time: 10 minutes

Instructions

  1. Open four applications one at a time:
    a. Open File Explorer (Win+E)
    b. Open Notepad (Windows key, type "Notepad," Enter)
    c. Open Calculator (Windows key, type "Calculator," Enter)
    d. Open your web browser (click its icon on the taskbar)

  2. Practice Alt+Tab:
    a. Hold down Alt and press Tab once. A preview of all open windows appears.
    b. While still holding Alt, press Tab again to move to the next window.
    c. Press Tab a third time to move to the next one.
    d. Release Alt to switch to the highlighted window.
    e. Repeat this several times until you can quickly switch to any specific app.

  3. Practice Win+D (Show Desktop):
    a. All four apps should be open on screen.
    b. Press Win+D. All windows minimise and you see the desktop.
    c. Press Win+D again. All windows restore to where they were.
    d. Do this three times to get the feel of it.

  4. Combined practice:
    a. Use Alt+Tab to switch to Notepad.
    b. Type: "I switched to Notepad using Alt+Tab."
    c. Use Alt+Tab to switch to the browser.
    d. Use Alt+Tab to switch to Calculator.
    e. Press Win+D to show the desktop.
    f. Click the Notepad icon on the taskbar to bring it back.
    g. Press Ctrl+S to save.

  5. Close all four apps using Alt+F4 (press it in each window).

Expected Result

You can switch between multiple open apps smoothly using Alt+Tab without needing to click taskbar icons. You can minimise everything with Win+D and restore it. These shortcuts dramatically speed up your workflow.

Bonus Challenge

Try opening six or seven apps and practise switching to a specific one using Alt+Tab. Also try Alt+Shift+Tab which cycles through apps in the opposite direction.

Practice Task 5: Start Your Typing Journey

Objective: Sign up for a typing practice website and complete your first lessons.
Difficulty: Beginner
Time: 25 minutes

Instructions

  1. Open your web browser (Edge or Chrome).
  2. In the address bar at the top, type typingclub.com and press Enter.
  3. Click "Sign Up" or "Get Started" (it is free).
  4. Create an account using your email address, or sign up with Google.
  5. Once logged in, you will see the first typing lesson.
  6. Before you begin: Place your fingers on the home row:
  7. Left hand: A (pinky), S (ring), D (middle), F (index)
  8. Right hand: J (index), K (middle), L (ring), ; (pinky)
  9. Feel for the bumps on F and J.
  10. Complete Lessons 1 through 5. These cover the home row keys.
  11. At the end of lesson 5, the website will show you a report with your WPM (words per minute) and accuracy percentage.
  12. Record your starting stats: Open Notepad and create a file called "Typing Progress.txt" in Documents. Write:
TYPING PROGRESS LOG
===================
Week 1 - [today's date]
Website: TypingClub
Lessons Completed: 1-5
WPM: ____
Accuracy: ____%
Notes: [how it felt, what was hard, what was easy]
  1. Save the file (Ctrl+S).

Expected Result

You have a TypingClub account and completed your first 5 lessons. Your starting WPM and accuracy are recorded. You have a progress log you will update weekly.

Bonus Challenge

After finishing TypingClub lessons, go to keybr.com and do a 5-minute practice session. Record your WPM from there as well. Compare the two.

Practice Task 6: Create a Shortcut Reference Card

Objective: Create a printed reference card of all essential shortcuts you can keep by your desk.
Difficulty: Intermediate
Time: 25 minutes

Instructions

  1. Open Notepad (or if you have learned to use Word, open that instead).
  2. Type the following content, formatted neatly:
MY KEYBOARD SHORTCUT REFERENCE CARD
====================================

EDITING
-------
Ctrl+C    Copy
Ctrl+V    Paste
Ctrl+X    Cut
Ctrl+Z    Undo
Ctrl+Y    Redo
Ctrl+A    Select All
Ctrl+S    SAVE (use constantly!)
Ctrl+P    Print
Ctrl+F    Find text

WINDOWS NAVIGATION
------------------
Alt+Tab         Switch between open apps
Win+D           Show Desktop / Restore windows
Win+E           Open File Explorer
Win+L           LOCK computer (use when leaving desk!)
Win+Shift+S     Screenshot (select area)
PrtSc           Screenshot (full screen)
Alt+F4          Close current app
Ctrl+Shift+Esc  Open Task Manager
Win+I           Open Settings

FILE MANAGEMENT
---------------
F2              Rename selected file
Delete          Send to Recycle Bin
Shift+Delete    Permanently delete (careful!)
F5              Refresh

TYPING TIP
-----------
Home row: A S D F G H J K L ;
Bumps on F and J help you find home position.

Created on: [today's date]
  1. Press Ctrl+S to save. Save to Documents as "Shortcut Reference Card.txt."
  2. Press Ctrl+P to open the print dialog.
  3. If you have a printer connected, print this page.
  4. If you do not have a printer, save it and keep it as a digital reference (consider making it your desktop wallpaper by taking a screenshot of it).

Expected Result

A neatly formatted shortcut reference card, either printed and placed by your desk, or saved as a digital reference. You should consult this card whenever you forget a shortcut, and eventually you will have them all memorised.

Bonus Challenge

Make a second reference card specifically for the program you use most (your browser, Word, etc.) with shortcuts specific to that app.

Module Assessment

Answer these questions on paper or in a text file.

  1. What does the Ctrl key do by itself? What is it used for?
  2. What is the difference between Backspace and Delete?
  3. What does Caps Lock do? How can you tell if it is on?
  4. Name the keyboard shortcut for each action: Copy, Paste, Cut, Undo, Save.
  5. How do you take a screenshot of a selected area of your screen?
  6. What does Win+L do? When should you use it?
  7. What is the home row? Name all the keys on it.
  8. How do you find the home row without looking at the keyboard?
  9. What is the difference between left-click and right-click?
  10. How do you right-click using a laptop touchpad?

Scoring: Each question is worth 1 point. 8 or more correct = you are ready for Module 5. Below 8 = review the topics you missed.

Real-Life Mini Project: "Shortcut Speed Challenge"

Objective: Time yourself completing a real task using shortcuts vs. using only the mouse, and compare the difference.
Time: 20 minutes

Instructions

Round 1: Mouse only (no keyboard shortcuts)
1. Start a timer (use the Clock app or your phone).
2. Open Notepad using only the mouse (click Start, scroll to find Notepad, click it).
3. Type: "I am testing my speed with the mouse."
4. Select all text using only the mouse (click and drag across the text).
5. Copy using only the mouse (right-click, click Copy).
6. Click at the end, press Enter for a new line.
7. Paste using only the mouse (right-click, click Paste).
8. Save using only the mouse (click File, click Save As, choose location, type name, click Save).
9. Close Notepad using only the mouse (click the X).
10. Stop the timer. Write down: "Mouse only time: _____ seconds."

Round 2: Keyboard shortcuts only
1. Start the timer.
2. Open Notepad (Windows key, type "Notepad," Enter).
3. Type: "I am testing my speed with keyboard shortcuts."
4. Select all: Ctrl+A.
5. Copy: Ctrl+C.
6. Move to end and new line: End, Enter.
7. Paste: Ctrl+V.
8. Save: Ctrl+S (choose location, type name, Enter).
9. Close: Alt+F4.
10. Stop the timer. Write down: "Shortcut time: _____ seconds."

Compare: The shortcut method should be noticeably faster. Write down the difference and keep this as motivation to keep using shortcuts.

Expected Result

You have concrete evidence that keyboard shortcuts are faster than mouse-only navigation. This motivates you to keep practising shortcuts until they become second nature.
