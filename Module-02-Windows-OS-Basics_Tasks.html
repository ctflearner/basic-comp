Practice Task 1: Navigate Using File Explorer

Objective: Become comfortable moving between key folders in File Explorer.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Press Win+E to open File Explorer.
  2. In the left sidebar, click on "Desktop." Look at the files and folders that appear. These are the same icons you see on your desktop screen.
  3. Click the Back arrow (top-left corner, left-pointing arrow) to go back.
  4. Click on "Documents." Notice the address bar at the top changes to show your location.
  5. Click on "Downloads." This is where files from the internet are saved. Write down on paper how many files are currently in your Downloads folder.
  6. Click on "Pictures." Note what is here (it may be empty if you have not saved any pictures yet).
  7. Click on "This PC" in the left sidebar. You should see your hard drive (usually called "Local Disk (C:)"). Write down how much free space is available.
  8. If a USB pendrive is plugged in, it will also appear here. Note its name and size.

Expected Result

You have successfully navigated to Desktop, Documents, Downloads, Pictures, and This PC. You know where each folder is and what it contains. You wrote down the number of files in Downloads and the free space on your hard drive.

Bonus Challenge

Use the address bar at the top of File Explorer. Click on it, type C:\Users, and press Enter. You are now looking at the Users folder on your hard drive. Navigate back using the Back arrow.

Practice Task 2: Create a Folder Structure

Objective: Create an organised set of folders, like a filing system.
Difficulty: Beginner
Time: 20 minutes

Instructions

  1. Press Win+E to open File Explorer.
  2. Click on "Documents" in the left sidebar.
  3. Create the main folder:
    a. Right-click on an empty space in the main area.
    b. Hover over "New", then click "Folder."
    c. Type My Work and press Enter.
  4. Go inside the folder: Double-click on "My Work" to open it.
  5. Create a subfolder: Right-click on empty space, New, Folder. Name it School. Press Enter.
  6. Double-click on "School" to go inside it.
  7. Create another folder called Year 2024. Go inside it.
  8. Create another folder called Semester 1. Go inside it.
  9. Create a text file inside Semester 1:
    a. Right-click on empty space.
    b. Hover over "New", then click "Text Document."
    c. Name it Course Notes and press Enter.
  10. Double-click Course Notes.txt to open it.
  11. Type: "These are my notes for Semester 1."
  12. Press Ctrl+S to save.
  13. Close Notepad by clicking the X.
  14. Check the address bar at the top. It should read something like:
    Documents > My Work > School > Year 2024 > Semester 1

Expected Result

You have created a nested folder structure: Documents > My Work > School > Year 2024 > Semester 1, with a text file inside the deepest folder. The address bar confirms your location.

Bonus Challenge

Go back to "My Work" and create a second branch: My Work > Personal > Finances > 2024. Create a text file inside called "Budget.txt" and type a practice line in it.

Practice Task 3: Create, Rename, and Delete Folders

Objective: Practice managing folders -- creating, renaming, deleting, and recovering from Recycle Bin.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Open File Explorer (Win+E) and go to Documents.
  2. Create 3 folders:
    a. Right-click, New, Folder. Name it Test Folder A. Press Enter.
    b. Right-click, New, Folder. Name it Test Folder B. Press Enter.
    c. Right-click, New, Folder. Name it Test Folder C. Press Enter.
  3. Rename one folder:
    a. Click once on "Test Folder A" to select it (it becomes highlighted).
    b. Press F2 on your keyboard.
    c. The name becomes editable. Type Important Files and press Enter.
  4. Delete one folder:
    a. Click once on "Test Folder B" to select it.
    b. Press the Delete key on your keyboard.
    c. The folder disappears. It has gone to the Recycle Bin.
  5. Recover the deleted folder:
    a. Minimise or close File Explorer.
    b. On your desktop, find the Recycle Bin icon (it looks like a waste bin). Double-click it.
    c. Inside, you should see "Test Folder B."
    d. Right-click on "Test Folder B."
    e. Click "Restore."
    f. The folder returns to Documents.
  6. Go back to Documents and verify "Test Folder B" is back.
  7. Clean up: Delete all three test folders (select each one and press Delete). Then empty the Recycle Bin: right-click the Recycle Bin icon on the desktop and select "Empty Recycle Bin."

Expected Result

You successfully created 3 folders, renamed one, deleted one, recovered it from the Recycle Bin, and then cleaned everything up. You are comfortable with creating, renaming, deleting, and recovering files and folders.

Bonus Challenge

Try deleting a folder using Shift+Delete instead of just Delete. This permanently deletes it without sending it to the Recycle Bin. Be very careful with this -- there is no recovery. Only use it on test files.

Practice Task 4: Pin and Unpin Apps on the Taskbar

Objective: Customise your taskbar with the apps you use most.
Difficulty: Beginner
Time: 10 minutes

Instructions

  1. Pin the Calculator:
    a. Click the Start button (Windows icon on the taskbar).
    b. Type "Calculator" in the search bar.
    c. When Calculator appears in the results, right-click on it.
    d. Click "Pin to taskbar."
    e. Look at your taskbar -- the Calculator icon should now appear there.
  2. Pin Notepad:
    a. Click the Start button.
    b. Type "Notepad."
    c. Right-click on Notepad in the results.
    d. Click "Pin to taskbar."
  3. Pin File Explorer (it may already be pinned):
    a. Click the Start button.
    b. Type "File Explorer."
    c. Right-click on it and click "Pin to taskbar."
  4. Test your pinned apps: Click each pinned icon on the taskbar. The app should open. Close each one with the X button.
  5. Unpin one app:
    a. Find the Notepad icon on your taskbar.
    b. Right-click on it.
    c. Click "Unpin from taskbar."
    d. The icon disappears from the taskbar.

Expected Result

Your taskbar now has Calculator and File Explorer pinned (and Notepad was pinned and then unpinned). You can open any pinned app with a single click.

Bonus Challenge

Pin your web browser (Microsoft Edge or Google Chrome) and one more app of your choice. Arrange them by dragging the icons left or right on the taskbar.

Practice Task 5: Organise Your Downloads Folder

Objective: Apply real file management skills to organise your actual Downloads folder.
Difficulty: Intermediate
Time: 30 minutes

Instructions

  1. Open File Explorer (Win+E) and click on "Downloads" in the left sidebar.
  2. Look at the files in your Downloads folder. They might be disorganised.
  3. Create subfolders inside Downloads:
    a. Right-click on empty space, New, Folder. Name: Images. Press Enter.
    b. Create another folder: Documents.
    c. Create another folder: Videos.
    d. Create another folder: Software.
  4. Sort your existing files:
    a. Look at each file in the Downloads folder.
    b. Check the file type by looking at the icon or the file extension (the letters after the dot, like .pdf, .jpg, .mp4).
    c. Move image files (.jpg, .png, .gif) into the Images folder:
    • Right-click the file, click "Cut" (or press Ctrl+X).
    • Double-click the Images folder to go inside.
    • Right-click on empty space, click "Paste" (or press Ctrl+V).
    • Click the Back arrow to go back to Downloads.
      d. Move document files (.pdf, .docx, .txt) into the Documents folder the same way.
      e. Move video files (.mp4, .avi, .mkv) into the Videos folder.
      f. Move installer files (.exe, .msi) into the Software folder.
  5. When finished, your Downloads folder should have mostly just your four subfolders, with few or no loose files.

Expected Result

Your Downloads folder is now organised into four categories. You can quickly find any downloaded file. This is a real skill you will use every day.

Bonus Challenge

Delete files in Downloads that you no longer need (old installers, duplicate files). Remember, they go to the Recycle Bin first, so you can recover them if you make a mistake.

Module Assessment

Answer these questions on paper or in a text file to check your understanding.

  1. What is an operating system? Explain in your own words.
  2. Name three things the Windows operating system does for you.
  3. Where is the taskbar located? What is on the far-right side of it?
  4. How do you open the Start Menu? (Name two ways.)
  5. What is File Explorer used for? How do you open it? (Name two ways.)
  6. What are the four key folders in the left sidebar of File Explorer?
  7. Describe the steps to create a new folder inside Documents.
  8. How do you rename a file? (Describe two different methods.)
  9. What happens when you delete a file? Is it gone forever?
  10. What is the difference between Sleep, Restart, and Shut Down?

Scoring: Each question is worth 1 point. 8 or more correct = you are ready for Module 3. Below 8 = review the topics you missed.

Real-Life Mini Project: "Set Up Your Digital Workspace"

Objective: Create a personal folder system that you will actually use for organising your digital life.
Time: 30 minutes

Instructions

  1. Open File Explorer and go to Documents.
  2. Create the following folder structure that mirrors your real life:
Documents/
  Personal/
    Health/
    Finance/
    ID Documents/
  Work/
    CVs and Cover Letters/
    Training/
    Projects/
  Education/
    Courses/
    Certificates/
  1. Inside "CVs and Cover Letters," create a text file called "CV Draft.txt" and write your name, phone number, and email inside.
  2. Inside "Courses," create a text file called "Digital Skills Notes.txt" and write three things you learned today.
  3. Pin File Explorer to your taskbar if it is not already there.
  4. Connect to WiFi if you are not already connected.
  5. Check for Windows Updates (Start, type "Windows Update," Check for updates).

Expected Result

You have a real, organised folder system ready for daily use. Your taskbar has your most-used apps. Your computer is connected to the internet and up to date. You are set up to work efficiently.
