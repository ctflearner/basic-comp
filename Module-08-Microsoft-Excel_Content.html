Topic 1: What Is Microsoft Excel?

Explanation

Microsoft Excel is a spreadsheet program -- think of it as a giant, intelligent grid of boxes where you can store numbers, text, and dates, and then perform calculations on them automatically.

Imagine a notebook with graph paper. Each small square on the paper is a cell where you can write a number or a word. Now imagine that this notebook is magical -- you can tell it "add up all the numbers in this column" and it does it instantly. You can also tell it "if this number goes above 1000, turn the cell red" and it does that too. That is Excel.

Why Excel matters:

Who Uses It How They Use It
Students Track grades, manage study schedules, organize research data
Employees Track expenses, manage budgets, create reports
Business Owners Inventory management, sales tracking, payroll, invoices
Accountants Financial statements, tax calculations, auditing
Anyone Personal budget, household expenses, event planning

Excel is often the single most requested skill in job postings. Being comfortable with basic Excel formulas can set you apart from other candidates.

Real-World Example

A shop owner tracks daily sales in an Excel spreadsheet. Each row is one day, columns track items sold and amounts. At the bottom, Excel automatically calculates: total sales for the month, average daily sales, the busiest day (highest sales), and the slowest day (lowest sales). The shop owner makes better business decisions because the data is organized and the calculations are instant.

Key Points

  • Excel is for organizing data and performing calculations
  • It is the most requested software skill in job postings
  • A spreadsheet is like an intelligent grid that calculates for you

Topic 2: The Excel Interface

Explanation

When you open Excel and create a new blank workbook, you will see a grid of cells. Let us understand each part.

Step-by-Step Guide: Understanding the Interface

Workbook and Worksheets:
- A workbook is the entire Excel file (like a notebook)
- A worksheet (or sheet) is one page within the workbook (like a page in the notebook)
- You can see sheet tabs at the bottom of the screen: Sheet1, Sheet2, etc.
- Right-click a tab to rename it (e.g., "January," "February," "Sales")
- Click the + button next to the tabs to add a new sheet

Cells, Rows, and Columns:
- Columns run vertically (up and down) and are labeled with letters: A, B, C... Z, AA, AB...
- Rows run horizontally (left and right) and are labeled with numbers: 1, 2, 3, 4...
- A cell is one box in the grid -- the intersection of a column and a row
- Every cell has a unique cell reference made of its column letter and row number
- The cell at column A, row 1 is A1
- The cell at column C, row 5 is C5
- The cell at column D, row 10 is D10

Important Areas:

Area Location What It Shows
Name Box Top-left (shows "A1") The reference of the currently selected cell
Formula Bar Top (long bar next to Name Box) The contents or formula of the selected cell
Column Headers Top of the grid (A, B, C...) Click to select an entire column
Row Headers Left of the grid (1, 2, 3...) Click to select an entire row
Sheet Tabs Bottom of the screen Switch between worksheets
Status Bar Very bottom Shows SUM, AVERAGE, COUNT of selected cells

The Ribbon is the same concept as in Word -- tabs at the top (Home, Insert, Page Layout, Formulas, Data, Review, View) with groups of tools.

Key Points

  • A workbook is the file, a worksheet is one page/tab within it
  • Cells are identified by column letter + row number (A1, B5, C10)
  • The Name Box shows which cell is selected
  • The Formula Bar shows what is inside the selected cell

Topic 3: Navigating and Entering Data

Explanation

Moving around an Excel spreadsheet and entering data are the most fundamental skills. Let us master them.

Step-by-Step Guide

Selecting a Cell:
- Click on any cell to select it
- The cell gets a blue/green border, and its reference appears in the Name Box

Typing Data:
1. Click on a cell (e.g., A1)
2. Type your data (e.g., "Name")
3. Press Enter -- the cursor moves DOWN to the next row (A2)
4. Or press Tab -- the cursor moves RIGHT to the next column (B1)

Types of Data:

Type Example How Excel Treats It
Text Name, Address, "Hello" Aligns to the left by default
Number 100, 45.50, -20 Aligns to the right by default
Date 06/11/2026, 6-Nov-2026 Recognized as a date (can be calculated)
Formula =A1+B1 Starts with = sign, shows the result

Navigation Shortcuts:

Shortcut What It Does
Arrow keys Move one cell in that direction
Tab Move one cell to the right
Enter Move one cell down (and confirm entry)
Ctrl+Home Go to cell A1 (the very beginning)
Ctrl+End Go to the last used cell in the sheet
Ctrl+Arrow Jump to the edge of the data in that direction
Ctrl+G or F5 Go to a specific cell (type the reference)

Auto-Fill (A Huge Time Saver):

Auto-fill lets you quickly fill a series of data.

  1. Type Monday in cell A1
  2. Click on A1 to select it
  3. Look at the bottom-right corner of the cell -- you will see a small green square (called the fill handle)
  4. Click and drag this square downward through cells A2 to A7
  5. Excel automatically fills in: Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday

Auto-fill works with:
- Days of the week (Monday, Tuesday...)
- Months (January, February...)
- Number sequences (type 1 in A1 and 2 in A2, select both, then drag -- Excel continues: 3, 4, 5...)
- Dates (type a date, drag to fill consecutive dates)

Real-World Example

You are creating an attendance sheet. You type "Student 1" in A2, then use Auto-fill by dragging down to A30. Excel fills in "Student 2," "Student 3," all the way to "Student 29." You saved typing 28 entries by hand.

Key Points

  • Click a cell and type to enter data
  • Enter moves down, Tab moves right
  • Ctrl+Home goes to A1, Ctrl+End goes to the last used cell
  • Auto-fill (drag the green square) fills series automatically -- days, months, numbers

Topic 4: Editing and Basic Formatting

Explanation

After entering data, you will need to edit cells and format them to look clean and professional.

Step-by-Step Guide

Editing a Cell:
- Double-click a cell to enter edit mode (cursor appears inside the cell)
- Make your changes
- Press Enter to confirm, or Escape to cancel
- To clear a cell: select it and press the Delete key

Undo and Redo:
- Ctrl+Z -- Undo (go back one step). You can press it multiple times.
- Ctrl+Y -- Redo (redo what you undid)

Column Width:
- If text is too long for a cell, it overflows into the next cell (or gets cut off)
- To auto-fit column width: double-click the right border of the column header letter
- To manually resize: drag the right border of the column header

Row Height:
- Same concept: drag the bottom border of the row number, or double-click to auto-fit

Formatting Cells:

Select the cells you want to format, then use the Home tab:

Format How What It Does
Bold Ctrl+B Makes text bold
Font Size Font size dropdown Changes text size
Cell Color (Fill) Paint bucket icon Changes the cell background color
Font Color "A" with color bar icon Changes the text color
Borders Borders icon (grid square) Adds lines around cells
Merge Cells Merge & Center button Combines multiple cells into one (use sparingly)
Text Alignment Alignment buttons Left, center, right, top, middle, bottom
Wrap Text Wrap Text button Makes text wrap within the cell instead of overflowing

Number Formatting:

To change how numbers appear:
1. Select the cells with numbers
2. On the Home tab, find the Number section
3. Click the dropdown (shows "General" by default) and choose:

Format Example When to Use
Number 1,234.56 General numbers
Currency $1,234.56 or Rs 1,234.56 Money values
Percentage 45% Percentages (0.45 becomes 45%)
Date 06-Nov-2026 Dates
Text 001234 When you need leading zeros (like phone numbers)

Selecting Multiple Cells:

Action How
Select a range Click and drag from first cell to last cell
Select non-adjacent cells Hold Ctrl and click each cell
Select a range with keyboard Hold Shift and use arrow keys
Select entire row Click the row number on the left
Select entire column Click the column letter at the top
Select all cells Press Ctrl+A

Key Points

  • Double-click a cell to edit it, Delete key to clear it
  • Double-click a column border to auto-fit width
  • Use number formatting to display money, percentages, and dates correctly
  • Wrap Text prevents long text from overflowing
  • Use Merge Cells sparingly -- it can cause problems with formulas later

Topic 5: Basic Formulas -- The Most Important Part

Explanation

Formulas are what make Excel powerful. A formula is an instruction that tells Excel to perform a calculation. Every formula starts with the equals sign (=).

Think of it this way: when you type =2+3 in a cell, you are telling Excel "calculate 2 plus 3 and show me the answer." Excel displays 5 in the cell. But the real power comes when you use cell references instead of fixed numbers -- because then, if you change a number in one cell, every formula that uses it updates automatically.

Step-by-Step Guide

Basic Arithmetic:

Type these in any cell to try them:

Formula What It Does Result
=5+3 Addition 8
=10-4 Subtraction 6
=6*7 Multiplication 42
=20/4 Division 5
=2^3 Power (2 to the power of 3) 8

Using Cell References:

Instead of typing numbers directly, you refer to cells:

  1. Type 100 in cell A1
  2. Type 50 in cell B1
  3. In cell C1, type: =A1+B1
  4. Press Enter
  5. Cell C1 shows 150
  6. Now change A1 to 200 -- C1 automatically updates to 250

This is the core power of Excel: change one number, and everything connected to it recalculates.

Essential Functions:

Functions are pre-built formulas. They save you from writing long calculations by hand.

SUM -- Add Up Values:

=SUM(A1:A10)

This adds all values from cell A1 through A10. The colon (:) means "from A1 to A10."

AVERAGE -- Calculate the Average:

=AVERAGE(A1:A10)

Adds all values from A1 to A10 and divides by the count.

MAX -- Find the Highest Value:

=MAX(A1:A10)

Returns the largest number in the range.

MIN -- Find the Lowest Value:

=MIN(A1:A10)

Returns the smallest number in the range.

COUNT -- Count Cells with Numbers:

=COUNT(A1:A10)

Counts how many cells in the range contain numbers (ignores empty cells and text).

COUNTA -- Count Non-Empty Cells:

=COUNTA(A1:A10)

Counts how many cells are not empty (counts text and numbers).

IF -- Make a Decision:

=IF(A1>100, "Over Budget", "OK")

This checks: Is A1 greater than 100?
- If YES: displays "Over Budget"
- If NO: displays "OK"

The structure is: =IF(condition, value_if_true, value_if_false)

More IF examples:

=IF(B1>=35, "Pass", "Fail")          Checks if marks >= 35
=IF(C1>50000, "High", "Low")         Categorize salary
=IF(D1="Yes", "Approved", "Pending") Check text values

Percentage Calculation:

=A1*0.18

Calculates 18% of the value in A1. For GST, tax, discounts.

If cell E1 contains the tax rate (0.18), use: *=A1E1

CONCATENATE / Join Text:

=CONCATENATE(A1, " ", B1)

Or the shorter version:

=A1&" "&B1

If A1 contains "Priya" and B1 contains "Sharma," the result is "Priya Sharma."

TODAY -- Current Date:

=TODAY()

Displays today's date. Updates automatically every day.

LEN -- Count Characters:

=LEN(A1)

Counts the number of characters in cell A1. Useful for checking if text is too long.

Real-World Example

You have a list of 10 students and their marks in 5 subjects (cells B2 to F11). For each student, you calculate:
- Total: =SUM(B2:F2)
- Average: =AVERAGE(B2:F2)
- Result: =IF(AVERAGE(B2:F2)>=35, "Pass", "Fail")

Then at the bottom:
- Class highest in Math: =MAX(B2:B11)
- Class lowest in Math: =MIN(B2:B11)
- Class average in Math: =AVERAGE(B2:B11)

Change any student's marks, and everything recalculates instantly.

Key Points

  • Every formula starts with = (equals sign)
  • SUM adds, AVERAGE averages, MAX/MIN find highest/lowest, COUNT counts
  • IF lets you make decisions based on conditions
  • Use cell references (A1, B5) instead of typing numbers directly
  • When you change a cell, all formulas connected to it update automatically

Topic 6: Cell References -- Relative vs Absolute

Explanation

Understanding cell references is crucial when you copy formulas from one cell to another. This is one of the most commonly confusing topics for beginners, so let us break it down carefully.

Relative Reference (default): When you copy a formula, the references change relative to where you paste it.

Example:
- Cell C1 contains: =A1+B1
- You copy C1 and paste it into C2
- C2 automatically becomes: =A2+B2 (the row numbers adjusted)

This is usually what you want -- if each row has its own data, the formula should refer to that row's cells.

Absolute Reference ($ sign): When you copy a formula, the reference does NOT change.

Example:
- Cell E1 contains the GST rate: 0.18
- Cell C2 contains: *=B2$E$1 (the $ signs lock E1)
- You copy C2 and paste into C3, C4, C5...
- Every formula still refers to $E$1 -- the GST rate cell

The $ sign locks the reference:
- $A$1 -- Both column and row are locked (fully absolute)
- $A1 -- Only column is locked, row can change
- A$1 -- Only row is locked, column can change

Step-by-Step Guide

When to use absolute references:

Use the $ sign when ONE cell contains a value that applies to ALL rows -- like a tax rate, discount percentage, exchange rate, or bonus multiplier.

How to add $ signs quickly:
1. Click on the cell with your formula
2. Click on the cell reference in the formula bar (e.g., click on "E1")
3. Press F4 on your keyboard
4. Each press of F4 cycles through: E1 then $E$1 then E$1 then $E1 then back to E1

Real-World Example

You have a price list. Column A has item names, Column B has prices. Cell E1 has the GST rate (18% = 0.18).

A B C (GST Amount) D (Total)
1 Item Price GST Rate: 0.18
2 Pen 20 =B2*$E$1 =B2+C2
3 Notebook 50 =B3*$E$1 =B3+C3
4 Bag 500 =B4*$E$1 =B4+C4

When you copy the formula in C2 down to C3 and C4, B2 changes to B3 and B4 (relative), but $E$1 stays as $E$1 (absolute). If the GST rate changes to 12%, you only update cell E1 -- all rows recalculate.

Key Points

  • Relative references (A1) change when you copy a formula -- rows and columns shift
  • Absolute references ($A$1) stay fixed when you copy a formula
  • Use absolute references for fixed values like tax rates, conversion factors, or percentages
  • Press F4 to quickly add or remove $ signs

Topic 7: Creating Tables and Sorting/Filtering

Explanation

An Excel table is a structured range of data with headers. Converting your data into a table gives you automatic filtering, formatting, and sorting -- making data much easier to work with.

Step-by-Step Guide

Step 1: Enter Your Data with Headers

First, organize your data with column headers in the first row:

A B C D
Name Department Salary City
Priya Engineering 60000 Delhi
Rahul Marketing 45000 Mumbai
Anita Engineering 75000 Delhi

Step 2: Convert to a Table
1. Click any cell within your data
2. Go to Insert tab
3. Click Table
4. Excel automatically detects the range of your data
5. Make sure "My table has headers" is checked
6. Click OK

Your data now has:
- Banded row colors (alternating light/dark rows for readability)
- Dropdown arrows in each header cell (for filtering)
- A Table Design tab on the Ribbon for formatting

Step 3: Sorting

Sorting rearranges your rows based on the values in a column.

  1. Click the dropdown arrow on the column header you want to sort by
  2. Choose:
  3. Sort A to Z (ascending -- smallest to largest, A before Z)
  4. Sort Z to A (descending -- largest to smallest, Z before A)
  5. The entire table rearranges -- all data in each row stays together

You can also: go to Data tab, click Sort, and sort by multiple columns (e.g., sort by Department first, then by Salary within each department).

Step 4: Filtering

Filtering shows only the rows that match your criteria -- the rest are hidden (not deleted).

  1. Click the dropdown arrow on a column header (e.g., "Department")
  2. Uncheck Select All
  3. Check only the values you want to see (e.g., check only "Engineering")
  4. Click OK
  5. Only Engineering department rows are now visible

Filter by condition:
1. Click the dropdown arrow
2. Choose Number Filters (or Text Filters)
3. Select a condition:
- Greater Than (e.g., Salary > 50000)
- Between (e.g., Salary between 40000 and 70000)
- Contains (e.g., Name contains "a")
4. Enter the value and click OK

To clear a filter: Click the dropdown arrow and select Clear Filter from [Column Name].

To remove all filters at once: Go to Data tab and click Clear in the Sort & Filter group.

Key Points

  • Tables add automatic filtering, formatting, and sorting to your data
  • Sorting rearranges rows by a column's values (ascending or descending)
  • Filtering shows only rows that match your criteria (hides the rest)
  • Filtered rows are hidden, not deleted -- clear the filter to see all data again

Topic 8: Creating Charts

Explanation

Charts turn numbers into pictures. A column of numbers is hard to interpret at a glance, but a chart immediately shows patterns, trends, and comparisons. Choosing the right chart type is important.

Step-by-Step Guide

Step 1: Select Your Data
- Select the data you want to chart, INCLUDING the headers
- For example: select the "Month" column and the "Sales" column

Step 2: Insert a Chart
1. Go to Insert tab
2. In the Charts section, click the chart type you want

Choosing the Right Chart:

Chart Type Best For Example
Column/Bar Comparing values across categories Sales by product, marks by subject
Line Showing trends over time Monthly revenue, temperature over a week
Pie Showing proportions of a whole (percentages) Expense breakdown, market share

Step 3: Customize Your Chart

After inserting the chart, click on it to see the Chart Design and Format tabs.

Add a Chart Title:
1. Click on the chart
2. Click on the default "Chart Title" text at the top
3. Type your title (e.g., "Monthly Sales for 2026")

Add Data Labels:
1. Click on the chart
2. Click the + button (Chart Elements) that appears next to the chart
3. Check Data Labels
4. Numbers appear on each bar/slice/point

Add Axis Labels:
1. Click the + button
2. Check Axis Titles
3. Click on each axis title to type a name (e.g., "Month" for the horizontal axis, "Sales (Rs)" for the vertical axis)

Add a Legend:
- The legend shows which color represents which data series
- Click the + button and check Legend
- Position it at the top, bottom, left, or right

Resize the Chart:
- Click on the chart to select it
- Drag the corner handles to resize

Move the Chart:
- Click on the chart border and drag it to a new position on the sheet
- Or right-click the chart and select Move Chart to put it on a separate sheet

Real-World Example

You tracked your daily expenses for a month. You create:
1. A pie chart showing what percentage goes to Food, Transport, Bills, Shopping, and Entertainment -- you immediately see Food is 40% of your spending
2. A line chart showing daily spending over the month -- you see spending spikes on weekends
3. A column chart comparing this month's category totals to last month's -- you see Entertainment went up by 30%

Key Points

  • Select data including headers before inserting a chart
  • Column/Bar for comparisons, Line for trends over time, Pie for proportions
  • Always add a chart title and axis labels
  • Use the + button next to the chart to add/remove elements (title, labels, legend)

Topic 9: Printing Spreadsheets

Explanation

Printing spreadsheets requires more attention than printing Word documents because spreadsheets can be very wide and very long. You need to control what gets printed and how it fits on the page.

Step-by-Step Guide

Step 1: Preview Before Printing
- Press Ctrl+P to open Print Preview
- Check: Does your data fit on the page? Are columns cut off?

Step 2: Set the Print Area (Optional)

If you only want to print a specific part of the spreadsheet:
1. Select the cells you want to print
2. Go to Page Layout tab
3. Click Print Area then Set Print Area
4. Now only the selected area will print

Step 3: Adjust Page Settings

Go to Page Layout tab:

Setting Where Tip
Orientation Page Layout tab, Orientation Use Landscape for wide tables
Size Page Layout tab, Size Match your paper (A4 or Letter)
Margins Page Layout tab, Margins Use Narrow to fit more columns
Scaling Page Layout tab, Scale to Fit group Set Width to "1 page" to squeeze all columns onto one page

Step 4: Print Titles (Repeat Headers on Every Page)

For long spreadsheets that span multiple printed pages:
1. Go to Page Layout tab
2. Click Print Titles
3. In "Rows to repeat at top," click the row selection button and select your header row (e.g., Row 1)
4. Click OK
5. Now your column headers print at the top of every page

Step 5: Print
- Press Ctrl+P
- Verify in the preview
- Select your printer (or "Microsoft Print to PDF" for a PDF)
- Click Print

Key Points

  • Always preview before printing (Ctrl+P)
  • Use Landscape orientation for wide spreadsheets
  • Set a Print Area to print only what you need
  • Use Print Titles to repeat header rows on every printed page
  • Scale to Fit ensures all columns fit on one page width
