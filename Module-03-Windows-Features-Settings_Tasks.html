Practice Task 1: Explore Task Manager

Objective: Open Task Manager, identify resource-hungry apps, and close a non-essential one.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Before starting, open several apps: a web browser, File Explorer, Calculator, and Notepad. This gives Task Manager something to show.
  2. Press Ctrl+Shift+Esc to open Task Manager.
  3. If Task Manager opens in a simplified view, click "More details" at the bottom to see the full view.
  4. You are now on the Processes tab. Look at the list of running apps and background processes.
  5. Click the "Memory" column header to sort by memory usage (highest first).
  6. Write down on paper:
  7. The top 3 apps using the most memory (RAM)
  8. The amount of memory each one is using (shown in MB)
  9. Now click the "CPU" column header. Write down which app is using the most CPU right now.
  10. Click on the Performance tab at the top. Look at the CPU and Memory graphs.
  11. Write down: CPU usage percentage and Memory usage (e.g., "6.2 GB out of 8 GB").
  12. Go back to the Processes tab.
  13. Click on Calculator to select it.
  14. Click "End task" at the top right.
  15. Calculator closes. Notice it disappears from the list.
  16. Close Task Manager by clicking the X.

Expected Result

You successfully opened Task Manager, identified which apps are using the most resources, read your computer's current CPU and RAM usage, and closed an app using End Task. You have written notes on your computer's current performance.

Bonus Challenge

Open 10 tabs in your web browser and watch the Memory usage increase in Task Manager. Then close the tabs one by one and watch it decrease. This demonstrates how browsers use RAM.

Practice Task 2: Personalise Your Desktop

Objective: Change your wallpaper, enable dark mode, and set a custom lock screen.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Change your wallpaper:
    a. Right-click on an empty area of your desktop.
    b. Click "Personalise."
    c. Click "Background."
    d. Under "Personalise your background," select "Picture."
    e. You can choose from the default images Windows provides, or click "Browse photos" to select a picture from your computer.
    f. If you do not have a photo you like, select one of the default Windows images.
    g. Your wallpaper changes immediately.

  2. Enable dark mode:
    a. Press Win+I to open Settings.
    b. Click "Personalisation" in the left sidebar.
    c. Click "Colours."
    d. Under "Choose your mode," select "Dark."
    e. The Settings window and other apps switch to dark backgrounds.

  3. Change the accent colour:
    a. While still in Colours, scroll down to "Accent colour."
    b. Choose a colour you like from the palette.
    c. Notice how buttons and highlights change to that colour.

  4. Set a custom lock screen:
    a. Go to Settings, then Personalisation, then Lock screen.
    b. Under "Personalise your lock screen," select "Picture."
    c. Click "Browse photos" and select an image.
    d. Press Win+L to lock your computer and see your new lock screen.
    e. Type your password or PIN to log back in.

Expected Result

Your desktop has a new wallpaper, Windows is in dark mode with a custom accent colour, and your lock screen shows your chosen image. Your computer feels more personal and comfortable to use.

Bonus Challenge

Try the "Slideshow" option for your wallpaper. Choose a folder of images and set them to rotate every 10 minutes.

Practice Task 3: Install and Uninstall an Application

Objective: Safely install an app from the Microsoft Store and then uninstall it.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Install an app from Microsoft Store:
    a. Click the Start button and type "Microsoft Store." Open it.
    b. In the search bar at the top, type "PDF" (or another type of app you would find useful).
    c. Browse the results. Find a free app that interests you. Look for apps with high ratings (4 stars or above).
    d. Click on the app to see its details (description, screenshots, reviews).
    e. Click the "Get" button (or "Install" if it says that instead).
    f. Wait for the download and installation. A progress bar shows the status.
    g. When it says "Open," click it to test the app.
    h. Close the app when you are done testing.

  2. Uninstall the app:
    a. Click the Start button.
    b. Type "Installed apps" and click on it.
    c. In the search bar, type the name of the app you just installed.
    d. When you find it, click the three dots (...) to the right of the app name.
    e. Click "Uninstall."
    f. Confirm by clicking "Uninstall" again when prompted.
    g. The app is removed from your computer.

  3. Verify it is gone: Try searching for the app in the Start Menu. It should no longer appear.

Expected Result

You installed an app from the Microsoft Store, used it briefly, and then uninstalled it cleanly. You now know the safe way to add and remove software from your computer.

Bonus Challenge

Try finding and installing a useful free app you will actually keep, such as a note-taking app, a weather app, or a media player.

Practice Task 4: Download and Extract a ZIP File

Objective: Download a ZIP file and extract its contents.
Difficulty: Beginner
Time: 15 minutes

Instructions

Since you may not have a ZIP file readily available, we will create one first and then practice extracting it.

  1. Create files to compress:
    a. Open File Explorer (Win+E) and go to Documents.
    b. Create a new folder called ZIP Practice.
    c. Go inside it.
    d. Create three text files: right-click, New, Text Document. Name them Note1.txt, Note2.txt, Note3.txt.
    e. Open each file and type a sentence inside. Save each one (Ctrl+S) and close.

  2. Create a ZIP file:
    a. Select all three files: click on Note1.txt, then hold Ctrl and click Note2.txt and Note3.txt (all three should be highlighted/selected).
    b. Right-click on the selected files.
    c. Click "Compress to ZIP file" (or "Send to, Compressed (zipped) folder" on older versions).
    d. A new ZIP file appears. Name it MyNotes.zip and press Enter.

  3. Extract the ZIP file:
    a. First, delete the original three text files (select them, press Delete). This way you can see the extraction working.
    b. Right-click on MyNotes.zip.
    c. Click "Extract All..."
    d. Click "Extract" on the window that appears.
    e. A new folder called "MyNotes" appears. Open it.
    f. You should see your three text files inside, restored.

Expected Result

You created a ZIP file from three text files, then extracted it to access the files again. You understand how compression works: multiple files packed into one smaller file, and extraction unpacks them.

Bonus Challenge

If you have received a ZIP file via email or download in the past, find it in your Downloads folder and extract it. Explore the contents.

Practice Task 5: System Health Check

Objective: Perform a complete health check on your computer and write a short report.
Difficulty: Intermediate
Time: 25 minutes

Instructions

  1. Check storage space:
    a. Press Win+I to open Settings.
    b. Go to System then Storage.
    c. Write down: total space, used space, and free space on your main drive.

  2. Run Disk Cleanup:
    a. Click Start and type "Disk Cleanup." Open it.
    b. Select your main drive (C:) and click OK.
    c. Wait for it to calculate.
    d. Check all the safe boxes (Temporary files, Temporary Internet Files, Thumbnails, Recycle Bin).
    e. Click OK, then "Delete Files."
    f. Write down how much space was freed.

  3. Check Windows Update status:
    a. Click Start and type "Windows Update." Open it.
    b. Click "Check for updates."
    c. Write down: is your computer up to date, or are there updates waiting?
    d. If updates are available and you have time, install them.

  4. Check antivirus status:
    a. Click Start and type "Windows Security." Open it.
    b. Look at the dashboard. Are all areas showing green checkmarks?
    c. Click "Virus & threat protection."
    d. Note when the last scan was performed.
    e. If it has been a while, click "Quick scan" to run one now.
    f. Write down: is your antivirus active and up to date?

  5. Write your report: Open Notepad and create a file called "System Health Report.txt" in your Documents folder. Write the following:

SYSTEM HEALTH REPORT
Date: [today's date]

Storage:
- Total: ___
- Used: ___
- Free: ___
- Space freed by Disk Cleanup: ___

Windows Updates:
- Status: [Up to date / Updates pending]

Antivirus:
- Windows Defender: [Active / Inactive]
- Last scan: [date]
- Threats found: [Yes / No]

Overall Status: [Healthy / Needs Attention]

Expected Result

You have a completed health check report saved to your Documents folder. Your computer has been cleaned up, is up to date, and has an active antivirus. You know how to perform this check regularly (recommended: once a month).

Bonus Challenge

Check your Task Manager Performance tab while running these checks. Write down current CPU usage percentage and RAM usage at the end of your report.

  4. An app is frozen and not responding. Describe the steps to close it without restarting the computer.

  10. Where do you check if your antivirus is active?

Scoring: Each question is worth 1 point. 8 or more correct = you are ready for Module 4. Below 8 = review the topics you missed.

Real-Life Mini Project: "Monthly Computer Maintenance"

Objective: Create a monthly routine to keep your computer healthy and fast.
Time: 20 minutes

Instructions

  1. Open Notepad and create a file called "Monthly Maintenance Checklist.txt" in Documents.
  2. Write the following checklist:
MY MONTHLY COMPUTER MAINTENANCE CHECKLIST
==========================================

[ ] Run Disk Cleanup
[ ] Check storage space (keep at least 10% free)
[ ] Check for Windows Updates and install them
[ ] Open Windows Security and run a Quick Scan
[ ] Check Task Manager for any apps using too much memory
[ ] Clean up Downloads folder (delete old files, organise the rest)
[ ] Empty the Recycle Bin
[ ] Check app permissions (camera, microphone)
[ ] Restart the computer (fixes many small issues)

Date completed: ___________
Notes: ___________
  1. Save the file (Ctrl+S).
  2. Set a reminder on your phone or calendar to open this file on the first of every month.
  3. Perform every item on the checklist right now as practice.

Expected Result

You have a maintenance checklist saved to your computer and a monthly reminder set. You have completed your first run of the checklist. Your computer is clean, updated, and secure.
