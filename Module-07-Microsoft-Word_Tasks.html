Module 7: Tasks & Assignments -- Mastering Microsoft Word

How to Use This File

Complete each task in order. Each task builds on skills from the previous one. Save ALL your completed documents -- you will need some of them in later modules. Every task works on any Windows 11 computer with Microsoft Word (2019 or Microsoft 365).

Task 1: Create an "About Me" Document

Difficulty: Beginner
Time: 20 minutes

Instructions

  1. Open Microsoft Word (Start Menu, type "Word")
  2. Click Blank document
  3. Save immediately as "About-Me.docx" on your Desktop (press Ctrl+S)
  4. Type a title on the first line: "About Me"
  5. Format the title: Heading 1 style (from the Styles section in Home tab)
  6. Center it (Ctrl+E)
  7. Press Enter and type three paragraphs about yourself:
  8. Paragraph 1: Your name, where you are from, and what you do
  9. Paragraph 2: Your hobbies and interests
  10. Paragraph 3: Your goals for learning computer skills
  11. Format the body text:
  12. Font: Calibri
  13. Size: 12
  14. Alignment: Left (Ctrl+L)
  15. Line spacing: 1.5 (Home tab, Line Spacing button, select 1.5)
  16. Make your name bold (select it, press Ctrl+B) in the first paragraph
  17. Make one sentence italic (select it, press Ctrl+I)
  18. Save again (Ctrl+S)

Expected Result

  • A clean, one-page document with a centered Heading 1 title
  • Three well-written paragraphs in Calibri 12pt, left-aligned, 1.5 spacing
  • Your name is bold, one sentence is italic
  • File saved as "About-Me.docx" on your Desktop

Bonus Challenge

Add a horizontal line below the title (Home tab, Borders dropdown, Horizontal Line). Change the title font color to dark blue.

Task 2: Create a Formatted Formal Letter

Difficulty: Beginner to Intermediate
Time: 25 minutes

Instructions

  1. Open Word and create a new blank document
  2. Save as "Formal-Letter.docx" on your Desktop
  3. Set margins to Normal (1 inch all sides) via Layout tab, then Margins
  4. Set font to Times New Roman, size 12 for the entire document
  5. Type the following letter structure, formatting each part as described:

Your Address (right-aligned):

[Your Name]
[Your Street Address]
[City, State, PIN Code]
[Your Email]
[Date: e.g., 6 November 2026]
  • Select all these lines and press Ctrl+R (right-align)

Recipient Address (left-aligned):

The Manager
[Company Name]
[Company Address]
[City, State, PIN Code]
  • Press Ctrl+L (left-align)

Subject Line:

Subject: Application for the Position of [Job Title]
  • Make the word "Subject:" bold

Greeting:

Dear Sir/Madam,

Body (2-3 paragraphs):
- Paragraph 1: Why you are writing
- Paragraph 2: Your qualifications and why you are a good fit
- Paragraph 3: Closing remarks and request for interview

Sign-off:

Yours faithfully,

[Your Name]
  1. Set line spacing to 1.15 for the entire document
  2. Save the file (Ctrl+S)

Expected Result

  • A properly formatted formal letter following standard business letter conventions
  • Your address is right-aligned, recipient address is left-aligned
  • Professional font (Times New Roman 12pt), clean margins
  • Saved as "Formal-Letter.docx"

Bonus Challenge

Save a second copy as PDF (F12, then change "Save as type" to PDF). Compare the .docx and .pdf versions by opening both.

Task 3: Document with Tables, Images, Lists, and Headings

Difficulty: Intermediate
Time: 30 minutes

Instructions

Create a document that uses multiple Word features together.

  1. Open Word, create a new blank document, save as "Word-Skills-Demo.docx"

  2. Title: "My Word Skills Demonstration"

  3. Apply Heading 1 style

  4. Center it

  5. Section 1: Heading 2 -- "My Weekly Schedule"

  6. Insert a table with 5 columns and 4 rows:
    • Column headers: Time, Monday, Tuesday, Wednesday, Thursday
    • Fill in 3 rows with realistic schedule items

  7. Format the header row: bold text, light blue background color (select the row, use Shading button in Table Design)

  8. Section 2: Heading 2 -- "Things I Want to Learn"

  9. Create a bullet list with at least 5 items
  10. After the bullet list, add: "In this order:"

  11. Create a numbered list with the same 5 items, ranked by priority

  12. Section 3: Heading 2 -- "My Inspiration"

  13. Insert an image from your computer (any photo or image you have, or download a free one from pexels.com)
  14. Resize the image to about 3 inches wide (drag a corner handle)
  15. Set text wrapping to Square

  16. Write 2-3 sentences next to the image about why it inspires you

  17. Use three heading levels:

  18. At the end, add a Heading 3 under one of the sections for a sub-topic

  19. Save as .docx (Ctrl+S)

  20. Save as .pdf (F12, change type to PDF, Save)

Expected Result

  • A multi-section document demonstrating tables, images, bullet lists, numbered lists, and three heading levels
  • Table has formatted headers
  • Image has Square text wrapping with text beside it
  • Two saved files: .docx and .pdf versions

Bonus Challenge

Open the Navigation Pane (View tab, check "Navigation Pane"). Notice how your headings appear as a clickable outline on the left. Try clicking on a heading to jump to that section.

Task 4: Find & Replace Challenge

Difficulty: Beginner
Time: 10 minutes

Instructions

  1. Open Word and create a new document, save as "Find-Replace-Practice.docx"
  2. Type or paste the following paragraph:
The computer is one of the most important inventions of the modern 
age. Every office has a computer. Students use a computer to learn. 
Doctors use a computer to keep patient records. A computer can 
connect to the internet to access information. Without a computer, 
modern work would be nearly impossible. The computer has changed 
how we live, work, and communicate.
  1. Read the paragraph -- notice the word "computer" appears many times
  2. Press Ctrl+H to open Find and Replace
  3. In "Find what" type: computer
  4. In "Replace with" type: laptop
  5. Click Replace All
  6. Word will show how many replacements were made -- write down the number: ___
  7. Read the paragraph again -- every "computer" is now "laptop"
  8. Press Ctrl+Z to undo (this undoes the Replace All and brings back "computer")
  9. Now try again: replace just two instances by clicking Replace (not Replace All) -- click Find Next to preview, then Replace for just the ones you want
  10. Save the document

Expected Result

  • You successfully used Replace All to change every instance at once
  • You learned that Ctrl+Z can undo a Replace All
  • You practiced selective replacement using Replace one at a time
  • Number of replacements made by Replace All: 7

Bonus Challenge

Use Find & Replace to change all periods (.) to exclamation marks (!) -- just to see the effect. Then immediately undo it (Ctrl+Z). This shows how Replace All works with punctuation too.

Task 5: Headers, Footers, and Page Setup

Difficulty: Intermediate
Time: 15 minutes

Instructions

  1. Open Word, create a new blank document, save as "Page-Setup-Practice.docx"
  2. Set the following page properties:
  3. Margins: Custom -- 1 inch on all sides (Layout tab, Margins, Custom Margins)
  4. Paper size: A4 (Layout tab, Size, A4)
  5. Orientation: Portrait (Layout tab, Orientation, Portrait)

  6. Line spacing: 1.5 for all text (select all with Ctrl+A, then set 1.5 spacing)

  7. Add a Header:

  8. Go to Insert tab, click Header, choose "Blank"
  9. Type your full name on the left side
  10. Press Tab twice to move to the right side, type today's date

  11. Click "Close Header and Footer"

  12. Add a Footer with Page Numbers:

  13. Go to Insert tab, click Footer, choose "Blank"
  14. Go to Insert tab again, click Page Number, select "Current Position" then a centered style

  15. Click "Close Header and Footer"

  16. Add Content:

  17. Type a title: "Practice Document" (Heading 1, centered)
  18. Type enough text to fill at least 2 pages (you can write about any topic, or type placeholder text)

  19. Tip: To quickly add placeholder text, type =lorem(5,5) and press Enter -- Word generates five paragraphs of sample text

  20. Add a Page Break:

  21. After the first paragraph, press Ctrl+Enter to force a page break

  22. Type "Page Two Content" as a Heading 2 on the new page

  23. Scroll through the document and verify:

  24. Your name appears in the header on every page
  25. Page numbers appear in the footer (Page 1, Page 2, etc.)

  26. Margins are consistent

  27. Save the document

Expected Result

  • A multi-page document with custom margins and A4 size
  • Header shows your name and date on every page
  • Footer shows automatic page numbers
  • A deliberate page break between sections
  • 1.5 line spacing throughout

Bonus Challenge

Go to the header and add a horizontal line below your name (with the header editing area open, go to Home tab, Borders dropdown, Bottom Border). This creates a professional-looking header divider line.

Task 6: Real-Life Project -- Create Your Resume

Difficulty: Intermediate
Time: 40 minutes

Instructions

This is the most important task in this module. You are creating a real resume that you can use for actual job applications.

Step 1: Set Up the Document
- Open Word, create a new blank document
- Save as "Resume-[YourName].docx" on your Desktop
- Set margins to Narrow (0.5 inches) -- this gives more space for content
- Set font to Calibri for the whole document

Step 2: Name and Contact Section (Top)
- Type your full name in large font (size 20-24, bold, centered)
- Below it, type your contact info on one line, separated by vertical bars:
City, State | Phone: 98765-43210 | email@gmail.com
- Font size 10-11, centered
- Add a horizontal line below (Home tab, Borders, Horizontal Line)

Step 3: Objective/Summary Section
- Type "OBJECTIVE" (bold, size 12, all caps)
- Add a thin line below it (select the heading, Borders, Bottom Border)
- Write 1-2 sentences about what kind of role you are seeking
- Example: "Motivated and detail-oriented individual seeking a Data Entry position where I can apply my computer skills and attention to detail."

Step 4: Education Section
- Type "EDUCATION" (bold, size 12, all caps, with bottom border)
- List your education (most recent first):
Degree/Certificate Name Year Institution Name, City
- Degree name on the left (bold), year on the right (use a right-aligned tab stop)

Step 5: Skills Section
- Type "SKILLS" (bold, size 12, all caps, with bottom border)
- Create a two-column layout using a table (Insert Table, 2 columns, hide borders):
- Microsoft Word - Email Communication - Microsoft Excel - Internet Research - Microsoft PowerPoint - Fast Typing (XX WPM)

Step 6: Experience Section (if applicable)
- Type "EXPERIENCE" (bold, size 12, all caps, with bottom border)
- If you have work experience:
Job Title — Company Name Start Date – End Date - Achievement or responsibility 1 - Achievement or responsibility 2
- If you have no experience yet:
Fresher — eager to learn and contribute to a professional team. Completed Digital Skills Training covering MS Office, email, and internet proficiency.

Step 7: Languages Section
- Type "LANGUAGES" (bold, size 12, all caps, with bottom border)
- List languages you speak and your proficiency:
English (Proficient), Hindi (Native), [Others]

Step 8: Final Formatting
- Set line spacing to 1.0 or 1.15 (resumes should be compact)
- Make sure the entire resume fits on ONE page
- Review spacing -- no section should feel too cramped or too empty
- Run Spell Check (press F7)

Step 9: Save in Both Formats
- Save as .docx (Ctrl+S)
- Save as .pdf (F12, change type to PDF)
- The PDF version is what you will send to employers

Expected Result

  • A professional, one-page resume
  • Clear sections: Name/Contact, Objective, Education, Skills, Experience, Languages
  • Consistent formatting throughout
  • Saved as both .docx (for editing) and .pdf (for sharing)
  • You can actually use this resume for real job applications

Bonus Challenge

Create a second version of your resume targeted at a different job. Change the Objective and reorder the Skills section to highlight what that specific job requires. Save as "Resume-[YourName]-Version2.pdf". This teaches you that resumes should be customized for each application.

Module Assessment

  1. What keyboard shortcut saves your document?
  2. What is the difference between Save (Ctrl+S) and Save As (F12)?
  3. Name the three font styles every professional should know (bold, italic, underline) and their shortcuts.
  4. Why should you use Heading styles instead of just making text bigger and bolder?
  5. What is the shortcut for Find & Replace?
  6. How do you insert a page break?
  7. What is the difference between .docx and .pdf formats? When would you use each?
  8. How do you change the page orientation from Portrait to Landscape?
  9. What do the red and blue underlines in Word mean?
  10. You have a 30-page report. You need to change every instance of "2023" to "2024." How would you do this efficiently?

Real-Life Mini Project

Scenario: You are the secretary of a small community group (sports club, study group, or neighborhood association). Create the following three documents:

  1. Meeting Notice (1 page):
  2. Title: "[Group Name] Monthly Meeting Notice"
  3. Date, time, location of meeting
  4. Agenda (numbered list of 5 discussion items)

  5. Footer with the group's contact information

  6. Member Contact List (1 page):

  7. A table with columns: Name, Phone, Email, Role
  8. At least 8 rows of (fictional) member data

  9. Header row formatted with bold text and shading

  10. Meeting Minutes (1-2 pages):

  11. Header with group name and date
  12. Heading 1: "Meeting Minutes"
  13. Heading 2 for each agenda item
  14. Bullet points for decisions made under each item
  15. Footer with page numbers

Save all three as both .docx and .pdf. This project practices: formatting, tables, lists, headings, headers, footers, page numbers, and saving in multiple formats.
