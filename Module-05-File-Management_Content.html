Topic 1: The File System Hierarchy

Explanation

Every file on your computer lives inside an organised structure, like a building with floors, rooms, and items inside those rooms.

The hierarchy from biggest to smallest:

Drive (C:, D:, E:)
  Folder
    Subfolder
      File

Analogy: A Building

Building Computer
The entire building A drive (like C:)
A floor A folder
A room on that floor A subfolder
An item in the room (a book, a chair) A file

Drives:
- C: drive -- your main hard drive where Windows and most programs are installed.
- D: drive -- some computers have a second drive for extra storage.
- E:, F:, etc. -- these usually appear when you plug in a USB drive or external hard disk.

The path is the address of a file. It tells you exactly where to find it.

Example: C:\Users\John\Documents\Work\Report.docx

This means:
- C: -- the main drive
- Users -- a folder
- John -- a subfolder (your username)
- Documents -- a subfolder
- Work -- a subfolder
- Report.docx -- the actual file

You can see the path in the address bar at the top of File Explorer.

Step-by-Step Guide: Viewing the File System

  1. Open File Explorer (Win+E).
  2. Click on "This PC" in the left sidebar.
  3. You see all your drives listed: Local Disk (C:), and any other drives.
  4. Double-click on Local Disk (C:) to open it.
  5. You see folders like "Users," "Windows," "Program Files." These are top-level folders.
  6. Double-click on "Users," then on your username.
  7. You see your personal folders: Desktop, Documents, Downloads, Pictures, Music, Videos.
  8. Look at the address bar at the top. It shows the path to your current location.
  9. Click the Back arrow to go back one level at a time.

Real-World Example

When you save a report for work, it might go to:
C:\Users\YourName\Documents\Work\Reports\Monthly Report - October.docx

When someone asks you "Where is that file?", you can tell them the path. When you need to find a file, knowing the hierarchy helps you navigate directly to it instead of searching randomly.

Key Points to Remember

  • The file system is like a building: Drive, Folder, Subfolder, File
  • C: is your main drive
  • The path is the full address of a file
  • You can see the current path in the File Explorer address bar
  • Never modify or delete files in the "Windows" or "Program Files" folders -- these are system files

Topic 2: Copying Files

Explanation

Copying a file creates a duplicate. The original stays where it is, and a copy appears in the new location. You now have two identical copies.

Think of it like photocopying a document: the original stays in your hand, and the copy goes somewhere else.

Step-by-Step Guide: Copying Files

Method 1: Right-Click Menu
1. Find the file you want to copy.
2. Right-click on it.
3. Click "Copy" (or look for the copy icon).
4. Navigate to the destination folder (where you want the copy to go).
5. Right-click on an empty space in the destination folder.
6. Click "Paste."
7. The file appears in both the original and the new location.

Method 2: Keyboard Shortcuts (Faster)
1. Click on the file to select it.
2. Press Ctrl+C (Copy).
3. Navigate to the destination folder.
4. Press Ctrl+V (Paste).

Method 3: Drag and Drop (Between Drives)
When you drag a file from one drive to another (for example, from C: to a USB drive E:), Windows automatically copies it.
1. Open two File Explorer windows side by side (open File Explorer twice, or drag one window to the left edge and another to the right).
2. In one window, navigate to the file.
3. In the other window, navigate to the destination.
4. Click and drag the file from one window to the other.

Copying multiple files:
- Select several specific files: Hold Ctrl and click each file you want.
- Select a range of files: Click the first file, hold Shift, click the last file. All files between them are selected.
- Select all files in a folder: Press Ctrl+A.
- Then use Ctrl+C and Ctrl+V to copy them all at once.

Key Points to Remember

  • Copying creates a duplicate -- the original stays put
  • Ctrl+C then Ctrl+V is the fastest method
  • Hold Ctrl to select multiple individual files
  • Hold Shift to select a range of files
  • Ctrl+A selects all files in the current folder

Topic 3: Moving Files

Explanation

Moving a file takes it from one location and puts it in another. The original is removed from where it was. Unlike copying, you end up with only one copy of the file, in the new location.

Think of it like picking up a book from one shelf and putting it on a different shelf. The book is no longer on the first shelf.

Step-by-Step Guide: Moving Files

Method 1: Cut and Paste
1. Right-click on the file.
2. Click "Cut" (the file icon becomes slightly transparent/faded).
3. Navigate to the new location.
4. Right-click on empty space and click "Paste."
5. The file disappears from the original location and appears in the new one.

Method 2: Keyboard Shortcuts (Faster)
1. Click on the file to select it.
2. Press Ctrl+X (Cut).
3. Navigate to the new location.
4. Press Ctrl+V (Paste).

Method 3: Drag and Drop (Within the Same Drive)
When you drag a file within the same drive (e.g., from one folder to another on C:), Windows automatically moves it.

Copy vs. Move -- quick comparison:

Action Shortcut What Happens
Copy Ctrl+C then Ctrl+V Original stays, copy appears in new location
Move Ctrl+X then Ctrl+V Original removed, file appears only in new location

Real-World Example

You downloaded a photo to your Downloads folder, but you want it in your Pictures folder. You do not need two copies -- you just want it in the right place. So you move it: Ctrl+X in Downloads, then Ctrl+V in Pictures.

Key Points to Remember

  • Moving removes the file from the original location
  • Ctrl+X (cut) then Ctrl+V (paste) is the fastest method
  • Dragging within the same drive moves; dragging between drives copies
  • If you accidentally move a file, press Ctrl+Z immediately to undo

Topic 4: Deleting Files

Explanation

Deleting files removes them from the folder. But Windows gives you a safety net: deleted files go to the Recycle Bin first, where you can recover them if you change your mind.

Step-by-Step Guide: Deleting and Recovering Files

Deleting a file (to Recycle Bin):
1. Click the file to select it.
2. Press the Delete key. Or right-click and select "Delete."
3. The file goes to the Recycle Bin. It is not truly gone yet.

Permanently deleting a file (bypasses Recycle Bin):
1. Select the file.
2. Press Shift+Delete.
3. A confirmation dialog appears: "Are you sure you want to permanently delete this file?"
4. Click Yes.
5. The file is permanently gone. It cannot be recovered through normal means.

WARNING: Only use Shift+Delete when you are absolutely sure you will never need the file again. For everyday deleting, always use the regular Delete key so you have the Recycle Bin as a safety net.

Recovering a file from the Recycle Bin:
1. Double-click the Recycle Bin icon on your desktop.
2. Find the file you want to recover.
3. Right-click on it and select "Restore."
4. The file returns to its original location.

Emptying the Recycle Bin (to free up space):
1. Right-click the Recycle Bin icon on your desktop.
2. Click "Empty Recycle Bin."
3. Confirm by clicking "Yes."
4. All files in the Recycle Bin are permanently deleted and the disk space is freed.

Key Points to Remember

  • Delete key sends files to Recycle Bin (recoverable)
  • Shift+Delete permanently removes files (not recoverable -- be careful)
  • Right-click a file in the Recycle Bin and select "Restore" to get it back
  • Empty the Recycle Bin periodically to free up disk space

Topic 5: File Extensions

Explanation

A file extension is the letters after the dot in a filename. It tells your computer what type of file it is and which program should open it.

For example, in "Report.docx":
- "Report" is the file name
- ".docx" is the file extension (a Word document)

Common file extensions you will encounter:

Extension Type Opens With
.txt Plain text file Notepad
.docx Word document Microsoft Word
.xlsx Excel spreadsheet Microsoft Excel
.pptx PowerPoint presentation Microsoft PowerPoint
.pdf Portable Document Format Adobe Reader, Edge browser
.jpg / .jpeg Photo/image Photos app, any image viewer
.png Image (supports transparency) Photos app, any image viewer
.gif Animated image Browser, image viewer
.mp4 Video Media player, VLC
.avi Video (older format) Media player, VLC
.mp3 Audio/music Media player, Groove Music
.wav Audio (high quality) Media player
.zip Compressed folder File Explorer (Extract All)
.rar Compressed folder WinRAR or 7-Zip
.exe Program/installer Runs a program (be careful -- only open trusted .exe files)
.html Web page Browser

WARNING about .exe files: An .exe file is a program that runs on your computer. Only open .exe files you downloaded from trusted sources. A malicious .exe file can install viruses or damage your computer.

Step-by-Step Guide: Showing File Extensions

By default, Windows may hide file extensions. This is dangerous because you cannot see the true type of a file. Here is how to show them:

  1. Open File Explorer (Win+E).
  2. Click the "View" menu at the top.
  3. Hover over "Show".
  4. Click "File name extensions" to turn it on (a checkmark appears).
  5. Now every file shows its extension: "Report.docx" instead of just "Report."

Step-by-Step Guide: Viewing File Properties

  1. Right-click on any file.
  2. Click "Properties."
  3. A window shows:
  4. Type of file: e.g., "Text Document (.txt)"
  5. Opens with: Which program opens this file
  6. Location: The folder path where this file is stored
  7. Size: How much space it takes up
  8. Created: When the file was first created
  9. Modified: When it was last changed
  10. Click OK to close.

Key Points to Remember

  • File extensions tell your computer how to open a file
  • Always show file extensions (View, Show, File name extensions)
  • Be careful with .exe files -- only open ones from trusted sources
  • Right-click, Properties shows detailed information about any file

Topic 6: USB Drives and External Storage

Explanation

A USB drive (also called a pendrive, flash drive, or thumb drive) is a small portable storage device that plugs into your computer's USB port. It lets you carry files between computers.

An external hard disk is a larger portable storage device. It works the same way as a USB drive but holds much more data (500 GB to several terabytes).

Step-by-Step Guide: Using a USB Drive

Plugging in:
1. Find a USB-A port on your computer (rectangular slot on the side).
2. Insert the USB drive gently. If it does not fit, flip it and try the other way.
3. Wait a moment. You may hear a sound or see a notification.

Accessing the USB drive:
1. Open File Explorer (Win+E).
2. Click on "This PC" in the left sidebar.
3. Under "Devices and drives," you will see your USB drive listed (e.g., "USB Drive (E:)" or the brand name).
4. Double-click on it to see its contents.
5. You can now copy files to and from the USB drive, just like moving files between folders.

Safely removing the USB drive (CRITICAL):

You must ALWAYS safely eject a USB drive before pulling it out. If you just yank it out while files are being written, you can:
- Corrupt files on the USB drive (making them unreadable)
- Lose data
- In rare cases, damage the USB drive permanently

How to safely eject:

Method 1: System tray
1. Look at the bottom-right corner of the taskbar (system tray).
2. Click the small up arrow to show hidden icons.
3. Find the USB icon (it looks like a USB plug with a checkmark).
4. Click on it.
5. Click "Eject [name of your USB drive]."
6. Wait for the message: "Safe to remove hardware."
7. Now pull out the USB drive.

Method 2: File Explorer
1. Open File Explorer (Win+E).
2. Click on "This PC."
3. Right-click on your USB drive.
4. Click "Eject."
5. Wait for the safe-to-remove message.
6. Pull out the USB drive.

Key Points to Remember

  • USB drives are portable storage -- carry files between computers
  • Always safely eject before removing (system tray, USB icon, Eject)
  • Never pull out a USB drive while files are being copied
  • External hard disks work the same way but hold more data

Topic 7: Connecting Your Phone as Storage

Explanation

You can connect your smartphone to your computer with a USB cable to transfer files -- photos, videos, music, documents.

Step-by-Step Guide: Connecting an Android Phone

  1. Connect your phone to the computer using a USB cable (the same one you use for charging).
  2. Your phone's screen will show a notification: "USB connected" or "Charging this device via USB."
  3. Tap the notification on your phone.
  4. Select "File Transfer" or "MTP" (Media Transfer Protocol). This allows your computer to see your phone's files.
  5. On your computer, open File Explorer (Win+E).
  6. Under "This PC," your phone appears as a device (e.g., "Samsung Galaxy" or "Pixel").
  7. Double-click on your phone's name.
  8. You will see the phone's storage. Common folders:
  9. DCIM -- your photos and videos taken with the camera
  10. Downloads -- files downloaded on your phone
  11. Pictures -- screenshots and saved images
  12. Music -- music files
  13. Navigate to the folder you want and copy files to your computer (Ctrl+C on the phone file, Ctrl+V in a computer folder).

Step-by-Step Guide: Connecting an iPhone

iPhones work slightly differently:
1. Connect your iPhone to the computer with a USB cable.
2. If prompted on the iPhone, tap "Trust this Computer" and enter your passcode.
3. Open File Explorer on your computer.
4. Your iPhone appears under "This PC" as "Apple iPhone."
5. Double-click on it, then go to Internal Storage then DCIM.
6. You can copy photos and videos from here to your computer.

Note: iPhone file access from a PC is more limited than Android. For full file management, Apple recommends using iCloud or iTunes.

Key Points to Remember

  • Connect your phone with a USB cable
  • On Android: select "File Transfer" mode from the notification
  • On iPhone: tap "Trust this Computer"
  • DCIM folder contains your camera photos and videos
  • Always copy important photos to your computer as a backup

Topic 8: Backup Concepts

Explanation

A backup is a copy of your important files stored in a separate location. If your computer breaks, gets stolen, or gets a virus, you can restore your files from the backup.

Why backups matter:
- Hard drives can fail without warning
- Laptops can be stolen or dropped
- Viruses can encrypt or delete your files (ransomware)
- You might accidentally delete something important

The 3-2-1 Backup Rule:
- 3 copies of your important files
- 2 different types of storage (e.g., computer hard drive + USB drive)
- 1 copy stored offsite (e.g., cloud storage like OneDrive or Google Drive)

Where to store backups:

Method Pros Cons
USB Drive Cheap, portable, no internet needed Can be lost or damaged, limited space
External Hard Disk Large capacity, affordable Needs to be plugged in, can be damaged
Cloud Storage (OneDrive, Google Drive) Accessible from anywhere, safe from physical damage Needs internet, limited free space

Step-by-Step Guide: Creating a Basic Backup to USB Drive

  1. Plug in a USB drive.
  2. Open File Explorer (Win+E).
  3. Navigate to the folder you want to back up (e.g., Documents).
  4. Press Ctrl+A to select all files.
  5. Press Ctrl+C to copy.
  6. Navigate to the USB drive (This PC, then click on the USB drive).
  7. Create a folder on the USB drive called "Backup - [today's date]".
  8. Open that folder.
  9. Press Ctrl+V to paste all files.
  10. Wait for the copy to complete.
  11. Safely eject the USB drive.

Step-by-Step Guide: Using OneDrive (Cloud Backup)

OneDrive is Microsoft's cloud storage. If you have a Microsoft account, you get 5 GB of free storage.

  1. Click the Start button and type "OneDrive." Open it.
  2. Sign in with your Microsoft account (or create one if you do not have one).
  3. OneDrive creates a folder on your computer (usually in your user folder).
  4. Any file you put in the OneDrive folder automatically uploads to the cloud.
  5. Open File Explorer. You will see "OneDrive" in the left sidebar.
  6. Copy or move important files into the OneDrive folder.
  7. These files are now backed up to the cloud. You can access them from any computer or phone by logging into onedrive.com.

Real-World Example

Imagine your laptop is stolen from your bag. Without a backup, all your documents, photos, and work files are gone forever. With a backup on a USB drive at home and copies on OneDrive, you lose only the laptop -- all your files are safe and accessible from another computer.

Key Points to Remember

  • A backup is a copy of your important files in a separate location
  • Follow the 3-2-1 rule: 3 copies, 2 media types, 1 offsite
  • Back up regularly (at least once a month, weekly is better)
  • OneDrive gives you 5 GB free cloud storage with a Microsoft account
  • Losing files is stressful and often irreversible -- backups prevent this

Topic 9: The Recycle Bin

Explanation

The Recycle Bin is a special folder where deleted files go before they are permanently removed. It is your safety net.

How the Recycle Bin works:
1. You delete a file (Delete key or right-click, Delete).
2. The file moves to the Recycle Bin. It still takes up space on your drive.
3. You can restore it at any time (right-click, Restore) -- it goes back to its original location.
4. When you empty the Recycle Bin, the files are permanently deleted and the space is freed.

Recycle Bin settings:
1. Right-click the Recycle Bin icon on the desktop.
2. Click "Properties."
3. You can set the maximum size of the Recycle Bin. When it fills up, the oldest files are automatically deleted.
4. You can also change the setting to permanently delete files immediately (not recommended for beginners).

Key Points to Remember

  • Deleted files go to the Recycle Bin (not permanently gone)
  • Restore: right-click the file in Recycle Bin, click Restore
  • Empty the Recycle Bin to free disk space
  • Shift+Delete bypasses the Recycle Bin (permanent deletion)

Topic 10: Searching for Files

Explanation

As you use your computer more, you will accumulate hundreds or thousands of files. Knowing how to search quickly is essential.

Method 1: Windows Search (Taskbar)
1. Click the Search icon on the taskbar (magnifying glass) or press Win+S.
2. Type the name (or part of the name) of the file you are looking for.
3. Windows searches everywhere -- files, folders, apps, settings.
4. Click the result to open it, or click "Open file location" to see where it lives.

Method 2: File Explorer Search (Within a Folder)
1. Open File Explorer (Win+E).
2. Navigate to the folder you want to search in (e.g., Documents).
3. Click the search box in the top-right corner (or press Ctrl+F).
4. Type your search term.
5. Results appear as you type. Only files within this folder (and subfolders) are shown.

Searching by file type:

You can search for all files of a specific type using wildcards:
- *.pdf -- finds all PDF files
- *.jpg -- finds all JPG images
- *.docx -- finds all Word documents
- *.mp4 -- finds all MP4 videos

Type these in the File Explorer search box.

Step-by-Step Guide: Finding All PDFs on Your Computer

  1. Open File Explorer (Win+E).
  2. Click on "This PC" (so you search the entire computer).
  3. Click the search box in the top-right corner.
  4. Type: *.pdf
  5. Press Enter and wait. Windows searches all drives.
  6. A list of every PDF file on your computer appears.
  7. You can sort the results by name, date, or size by clicking the column headers.

Key Points to Remember

  • Win+S or the search icon searches everything on your computer
  • File Explorer search box searches within the current folder
  • Use *.extension to find all files of a specific type (e.g., *.pdf)
  • Searching is faster than manually browsing through folders

Common Mistakes to Avoid

  1. Confusing Copy and Move. Copy (Ctrl+C) leaves the original in place. Move (Ctrl+X) removes it. If unsure, use Copy -- you can always delete the original later.
  2. Pulling out a USB drive without ejecting. Always safely eject first. Pulling it out can corrupt files.
  3. Not showing file extensions. Without extensions visible, you cannot tell if a file is "Report.pdf" or "Report.exe" (which could be a virus disguised as a document). Always show extensions.
  4. Never backing up files. Hard drives fail. Laptops get stolen. Viruses delete files. Back up regularly.
  5. Searching the entire computer when you know the general area. Navigate to the right folder first, then search. It is much faster.
  6. Opening .exe files from untrusted sources. Only run .exe files you downloaded from official websites or the Microsoft Store.
  7. Forgetting Shift+Delete is permanent. There is no recovering a file after Shift+Delete. Use the regular Delete key for safety.
