Task 1: Personal Monthly Budget

Difficulty: Beginner
Time: 25 minutes

Instructions

  1. Open Microsoft Excel (Start Menu, type "Excel")
  2. Click Blank workbook

  3. Save immediately as "Monthly-Budget.xlsx" on your Desktop (Ctrl+S)

  4. Set up the Income section (rows 1-6):

  5. Cell A1: Type "PERSONAL MONTHLY BUDGET" (bold, font size 16, merge cells A1 to D1)
  6. Cell A3: Type "INCOME" (bold, font size 14)
  7. Enter these income sources:
A B
4 Salary 25000
5 Freelance Work 5000
6 Other Income 1000
7 Total Income =SUM(B4:B6)

  • Make row 7 bold

  • Set up the Expenses section (rows 9-18):

  • Cell A9: Type "EXPENSES" (bold, font size 14)
  • Enter these expense categories:
A B
10 Rent 8000
11 Food & Groceries 5000
12 Transport 2000
13 Electricity & Water 1500
14 Phone & Internet 800
15 Entertainment 1500
16 Clothing 1000
17 Medical 500
18 Miscellaneous 1000
19 Total Expenses =SUM(B10:B18)

  • Make row 19 bold

  • Calculate Savings (row 21):

  • Cell A21: "SAVINGS" (bold, font size 14)
  • Cell B21: =B7-B19 (Total Income minus Total Expenses)

  • Format B21 with green fill color if the number is positive

  • Format all money values:

  • Select all number cells (B4:B21)

  • Format as Currency (Home tab, Number section, choose Currency or use the Rs symbol)

  • Add borders around all data cells (Home tab, Borders, All Borders)

  • Save the file (Ctrl+S)

Expected Result

  • A clean budget spreadsheet with Income, Expenses, and Savings sections
  • SUM formulas calculate Total Income (31,000) and Total Expenses (21,300)
  • Savings shows 9,700 (Income minus Expenses)
  • All amounts are formatted as currency with borders

Bonus Challenge

Add a "Percentage" column (Column C) that shows what percentage each expense is of the total expenses. Formula: =B10/$B$19 and format as Percentage. Use absolute reference for the total.

Task 3: Product Price List with GST

Difficulty: Intermediate
Time: 25 minutes

Instructions

  1. Open Excel, create a new workbook, save as "Price-List-GST.xlsx"

  2. Set up the GST rate cell:

  3. Cell F1: Type "GST Rate:"
  4. Cell G1: Type 0.18 (18%)
  5. Format G1 as Percentage (it will show 18%)

  6. Make F1:G1 bold with yellow background

  7. Set up headers in Row 3:

A B C D E
Item Name Quantity Unit Price Subtotal GST Amount

  • Bold headers with light green background

  • Enter 20 products in rows 4-23. Examples:

A B C
Pen 10 15
Notebook 5 80
Eraser 20 5
Ruler 8 25
Pencil Box 3 150
(add 15 more items)
  1. Write formulas in Row 4, then copy down to Row 23:
  2. Column D (Subtotal): =B4*C4
  3. Column E (GST Amount): =D4*$G$1 (absolute reference to the GST rate)
  4. Column F (Grand Total): =D4+E4

Important: Use $G$1 (with dollar signs) for the GST rate. This is an absolute reference -- when you copy the formula down, it always refers to the GST rate cell.

  1. Add totals in Row 25:
  2. D25: =SUM(D4:D23) (Total Subtotal)
  3. E25: =SUM(E4:E23) (Total GST)
  4. F25: =SUM(F4:F23) (Grand Total)

  5. Make Row 25 bold

  6. Format:

  7. All money columns (C, D, E, F): Currency format
  8. Add borders around all data

  9. Auto-fit column widths (double-click each column border)

  10. Test the absolute reference:

  11. Change G1 from 0.18 to 0.12 (12% GST)
  12. Watch ALL GST amounts recalculate instantly

  13. Change it back to 0.18

  14. Save the file

Expected Result

  • A 20-item price list with Quantity, Unit Price, Subtotal, GST, and Grand Total
  • GST rate is in one cell (G1) and all GST formulas reference it with $G$1
  • Changing the GST rate updates all 20 rows instantly
  • Proper currency formatting and borders

Bonus Challenge

Add a "Discount" column between Subtotal and GST. Put a discount rate (e.g., 10% = 0.10) in another fixed cell. Calculate: Discounted Price = Subtotal - (Subtotal * discount rate). Then calculate GST on the discounted price.

Task 4: Sort and Filter Challenge

Difficulty: Intermediate
Time: 20 minutes

Instructions

  1. Open Excel, create a new workbook, save as "Employee-Data.xlsx"

  2. Create an employee database with these headers and 15 rows of data:

Name Department Salary City Join Date Experience (Years)

Departments to use: Engineering, Marketing, HR, Finance, Operations
Cities to use: Delhi, Mumbai, Bangalore, Chennai, Kolkata
Salary range: 25000 to 95000
Experience: 1 to 15 years

Enter 15 rows of realistic employee data with varied values across all columns.

  1. Convert to a Table:
  2. Click any cell in the data
  3. Go to Insert tab, click Table
  4. Confirm the range, make sure "My table has headers" is checked

  5. Click OK

  6. Sorting Tasks:

  7. Sort by Salary (highest to lowest): Click the Salary column dropdown, choose "Sort Largest to Smallest"
  8. Write down: Who has the highest salary? _______________

  9. Now sort by Name (A to Z): Click the Name column dropdown, choose "Sort A to Z"

  10. Filtering Tasks:

  11. Filter 1: Show only "Engineering" department employees

    • Click the Department dropdown, uncheck "Select All," check only "Engineering"
    • Write down: How many Engineering employees are there? ___
    • Clear the filter (click dropdown, select "Clear Filter")

  12. Filter 2: Show employees with Salary greater than 50000

    • Click the Salary dropdown, choose "Number Filters" then "Greater Than"
    • Type 50000, click OK
    • Write down: How many employees earn more than 50000? ___
    • Clear the filter

  13. Filter 3: Show employees in "Delhi" OR "Mumbai"

    • Click the City dropdown, uncheck "Select All," check only "Delhi" and "Mumbai"
    • Write down: How many employees are in Delhi or Mumbai? ___
    • Clear the filter

  14. Filter 4: Combined filter -- Engineering department AND Salary > 50000

    • First filter Department to "Engineering"
    • Then filter Salary > 50000 (both filters work together)
    • Write down: How many Engineering employees earn > 50000? ___
    • Clear all filters

  15. Save the file

Expected Result

  • A properly formatted table with 15 employee records
  • You successfully sorted by Salary and by Name
  • You performed 4 different filter operations and recorded the results
  • You understand that multiple filters work together (AND logic)

Bonus Challenge

Use the Data tab's Sort button to sort by TWO columns at once: first by Department (A to Z), then by Salary (Largest to Smallest) within each department. This groups employees by department and ranks them by salary within each group.

Task 6: Real-Life Project -- Household Expense Tracker

Difficulty: Intermediate to Advanced
Time: 40 minutes

Instructions

Create a comprehensive expense tracker that you could use in real life.

Step 1: Set Up the Workbook
- Open Excel, create a new workbook, save as "Expense-Tracker.xlsx"
- Rename Sheet1 to "Daily Log"

Step 2: Create the Daily Log Sheet

Set up headers in Row 1:
| A | B | C | D | E |
|---|---|---|---|---|
| Date | Item Description | Category | Amount | Payment Method |

Enter at least 25 expense entries for one month. Use realistic items:

Date Item Description Category Amount Payment Method
01-Nov-2026 Rice 5kg Food 350 Cash
01-Nov-2026 Bus ticket Transport 30 Cash
01-Nov-2026 Mobile recharge Bills 299 UPI
02-Nov-2026 Vegetables Food 120 Cash
02-Nov-2026 Movie ticket Entertainment 250 UPI

Categories to use: Food, Transport, Bills, Shopping, Entertainment, Others

Fill at least 25 entries spread across different dates and categories.

Step 3: Create the Summary Sheet

Add a new sheet, rename it "Summary"

Create a Category Summary table:
| A | B |
|---|---|
| Category | Total |
| Food | =SUMIF('Daily Log'!C:C,"Food",'Daily Log'!D:D) |
| Transport | =SUMIF('Daily Log'!C:C,"Transport",'Daily Log'!D:D) |
| Bills | =SUMIF('Daily Log'!C:C,"Bills",'Daily Log'!D:D) |
| Shopping | =SUMIF('Daily Log'!C:C,"Shopping",'Daily Log'!D:D) |
| Entertainment | =SUMIF('Daily Log'!C:C,"Entertainment",'Daily Log'!D:D) |
| Others | =SUMIF('Daily Log'!C:C,"Others",'Daily Log'!D:D) |
| Grand Total | =SUM(B2:B7) |

Note: SUMIF adds up values where a condition is met. The formula =SUMIF('Daily Log'!C:C,"Food",'Daily Log'!D:D) means "look at the Category column on the Daily Log sheet, find all rows where the category is Food, and add up the corresponding Amount values."

Add additional statistics:
- Average Daily Spending: =AVERAGE('Daily Log'!D:D)
- Highest Single Expense: =MAX('Daily Log'!D:D)
- Number of Transactions: =COUNTA('Daily Log'!D2:D100)

Step 4: Create a Pie Chart

On the Summary sheet:
1. Select the Category names and Totals (A1:B7, not including Grand Total)
2. Insert a Pie Chart
3. Add title: "Expense Distribution - November 2026"
4. Add data labels showing both category names and percentages
5. Resize to fill a good portion of the sheet

Step 5: Format Everything
- Daily Log: format Amount as Currency, Date as a proper date format
- Summary: format all totals as Currency
- Add borders, bold headers, colored header rows
- Auto-fit all columns

Step 6: Save
- Save as .xlsx

Expected Result

  • A "Daily Log" sheet with 25+ entries across 6 categories
  • A "Summary" sheet with SUMIF totals per category, grand total, average, max, and count
  • A pie chart showing the percentage breakdown of spending by category
  • Professional formatting throughout
  • This is a spreadsheet you could actually maintain in real life to track your spending

Bonus Challenge

Add a third sheet called "Payment Methods." Use SUMIF to calculate how much you spent via Cash, UPI, and Card separately. Create a bar chart comparing the three payment methods. Also add a COUNTIF formula to count how many transactions used each payment method.
