Task 1: Python — Name and Age Program

Instructions

  1. Open IDLE (Python's editor)
  2. Go to File > New File to open a blank editor window
  3. Write a Python program that:
  4. Asks the user for their name using input()
  5. Asks the user for their age using input() (convert to integer)
  6. Prints a greeting using f-strings: "Hello [name], you will be [age+1] next year!"
  7. Also prints: "You were born approximately in [current_year - age]"
  8. Save the file as name_age.py on your Desktop
  9. Run the program: press F5 (or Run > Run Module)
  10. Test it by entering your own details

Expected Code Structure

# My first Python program
name = input("What is your name? ")
age = int(input("How old are you? "))

# Your print statements here using f-strings
# ...

Expected Result

What is your name? Rahul
How old are you? 20
Hello Rahul, you will be 21 next year!
You were born approximately in 2006

Bonus Challenge

  • Add a third question: "What is your city?"
  • Print a full introduction: "Hello! I am [name], [age] years old, from [city]."
  • Ask for the user's favorite subject and print: "[name] loves studying [subject]!"

Task 2: Python — Calculator Program

Instructions

  1. Open IDLE and create a new file
  2. Write a program that:
  3. Prints "=== My Calculator ==="
  4. Asks the user for the first number (convert to float for decimal support)
  5. Asks the user for the operator (+, -, *, /)
  6. Asks the user for the second number (convert to float)
  7. Uses if/elif/else to perform the correct calculation
  8. Handles division by zero: If the user tries to divide by 0, print "Error: Cannot divide by zero!" instead of crashing
  9. Prints the result in the format: "5.0 + 3.0 = 8.0"
  10. If the user enters an invalid operator, prints "Error: Invalid operator!"
  11. Save as calculator.py on your Desktop
  12. Run and test with these inputs:
  13. 10 + 5 (should give 15.0)
  14. 20 - 8 (should give 12.0)
  15. 7 * 6 (should give 42.0)
  16. 15 / 4 (should give 3.75)
  17. 10 / 0 (should show error message, NOT crash)
  18. 5 ^ 2 (should show "Invalid operator!")

Expected Result

=== My Calculator ===
Enter first number: 15
Enter operator (+, -, *, /): /
Enter second number: 4
15.0 / 4.0 = 3.75

=== My Calculator ===
Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 0
Error: Cannot divide by zero!

Bonus Challenge

  • Add support for ** (power) and % (remainder) operators
  • After showing the result, ask "Calculate again? (yes/no)" — if yes, repeat. Use a while loop to keep the calculator running until the user types "no"
  • Add a // (integer division) operator

Task 3: Python — Marks Calculator (Pass/Fail)

Instructions

  1. Create a new Python file in IDLE
  2. Write a program that:
  3. Prints "=== Marks Calculator ==="
  4. Asks for the student's name
  5. Asks for marks in 5 subjects (one at a time). Example subjects: Math, Science, English, Hindi, Computer
  6. Store all marks in a list
  7. Calculate the total of all marks (use sum())
  8. Calculate the average (total divided by 5)
  9. Find the highest mark (use max())
  10. Find the lowest mark (use min())
  11. Print the results:
    • Student name
    • Each subject with its marks
    • Total marks (out of 500)
    • Average marks
    • Highest and lowest marks
    • Result: Pass if average >= 35, Fail if average < 35
  12. If average >= 75, also print "Distinction!"
  13. Save as marks_calculator.py
  14. Test with different sets of marks

Expected Result

=== Marks Calculator ===
Student name: Priya
Enter marks for Math: 85
Enter marks for Science: 72
Enter marks for English: 68
Enter marks for Hindi: 90
Enter marks for Computer: 95

=== Results for Priya ===
Math:     85
Science:  72
English:  68
Hindi:    90
Computer: 95
-----------------------
Total:    410 / 500
Average:  82.0
Highest:  95 (Computer)
Lowest:   68 (English)
Result:   PASS
Distinction!

Bonus Challenge

  • Validate that each mark is between 0 and 100. If someone enters 105 or -5, print "Invalid marks! Enter between 0 and 100." and ask again
  • Calculate a grade based on average: A (90+), B (75+), C (60+), D (35+), F (below 35)
  • At the end, ask "Check another student? (yes/no)" and loop if yes

Task 4: HTML — "My Profile" Page

Instructions

  1. Open Notepad
  2. Write an HTML page that includes ALL of the following:
  3. Proper HTML structure (<!DOCTYPE html>, <html>, <head>, <body>)
  4. A <title> tag with your name
  5. An <h1> heading with your full name
  6. An <h2> heading that says "About Me"
  7. A paragraph (<p>) about yourself — at least 3 sentences (where you are from, what you study, what you want to become)
  8. A photo of yourself (use <img> — save a photo in the same folder as your HTML file, or use an online image URL)
  9. An <h2> heading that says "My Hobbies"
  10. An unordered list (<ul>) with at least 5 hobbies
  11. An <h2> heading that says "Favorite Websites"
  12. An ordered list (<ol>) with links (<a>) to 3 websites you visit often. Each link should open in a new tab (target="_blank")
  13. A horizontal line (<hr>) before a footer paragraph that says "Created by [Your Name] - [Year]"
  14. Save as profile.html on your Desktop (File > Save As > All Files > profile.html)
  15. Double-click the file to open in Chrome
  16. Check that everything displays correctly

Expected Result

A webpage in your browser showing:
- Your name as a large heading
- A paragraph about you
- Your photo
- A bullet list of hobbies
- A numbered list of favorite websites (clickable links that open in new tabs)
- A footer with your name

Bonus Challenge

  • Add a background color to the body using inline CSS: <body style="background-color: #f5f5f5;">
  • Make the heading centered: <h1 style="text-align: center; color: darkblue;">
  • Add a border around your photo: <img style="border: 3px solid darkblue; border-radius: 10px;" ...>

Task 5: HTML — "My Favorite Foods" Table

Instructions

  1. Open Notepad
  2. Create an HTML page with a styled table of your 10 favorite foods
  3. The table must have:
  4. A title above the table: <h1>My Favorite Foods</h1>
  5. A table with 4 columns: Rank, Food Name, Cuisine, Rating (out of 5)
  6. 10 rows of data (your actual favorite foods)
  7. A header row with bold text (<th> tags)
  8. border="1" on the <table> tag
  9. Style with inline CSS:
  10. Header row: dark background color, white text
  11. Alternate rows: slightly different background colors (like light gray and white)
  12. All cells: padding of 10px
  13. Table: width 80%, centered on page
  14. Ratings of 5 should be in bold green text
  15. Ratings of 1-2 should be in red text
  16. Page background: a light color
  17. Save as foods.html and open in browser

Example Table Structure

<table style="width: 80%; margin: auto; border-collapse: collapse;">
    <tr style="background-color: #2c3e50; color: white;">
        <th style="padding: 12px;">Rank</th>
        <th style="padding: 12px;">Food</th>
        <th style="padding: 12px;">Cuisine</th>
        <th style="padding: 12px;">Rating</th>
    </tr>
    <tr style="background-color: #ffffff;">
        <td style="padding: 10px; text-align: center;">1</td>
        <td style="padding: 10px;">Biryani</td>
        <td style="padding: 10px;">Indian</td>
        <td style="padding: 10px; text-align: center; color: green; font-weight: bold;">5/5</td>
    </tr>
    <!-- Add 9 more rows -->
</table>

Expected Result

A nicely styled table in your browser with 10 foods, proper colors, and readable formatting.

Bonus Challenge

  • Add a "Notes" column with a short comment about each food
  • Add an image column with a small food image for each item (use free images from the internet)
  • Below the table, add a paragraph explaining your food preferences

Task 6: Real-Life Project — Personal Portfolio Website

Instructions

This is your final project for Module 11. You will create a multi-page personal website that you can show to employers, friends, or family.

Create 3 HTML pages in the same folder on your Desktop (create a folder called "my-portfolio"):

Page 1: Home Page (index.html)

Must include:
- Your full name as the main heading
- A professional-looking subtitle (e.g., "Computer Science Student | Tech Enthusiast")
- A paragraph introducing yourself (4-5 sentences)
- Your photo
- Navigation links to the other two pages: <a href="skills.html">My Skills</a> | <a href="contact.html">Contact Me</a>
- Styled with inline CSS: colors, centered text, background color, nice font

Page 2: Skills Page (skills.html)

Must include:
- Heading: "My Skills"
- Navigation links back to Home and to Contact
- A table listing at least 8 skills with columns: Skill Name, Category (Technical/Soft Skill), Level (Beginner/Intermediate/Advanced)
- Below the table, a section called "What I Am Learning" with a paragraph about this course
- An ordered list of your top 5 career goals
- Styled with CSS

Page 3: Contact Page (contact.html)

Must include:
- Heading: "Contact Me"
- Navigation links back to Home and Skills
- Your email address (as a clickable mailto link)
- Your phone number
- Links to your social media profiles (Instagram, LinkedIn, etc.) — each opening in a new tab
- A section called "Find Me Online" with links to your blog (from Module 10) and any other online presence
- A simple message: "Feel free to reach out for collaboration or just to say hello!"
- Styled with CSS

Styling Requirements (All Pages)

  • Consistent color scheme across all 3 pages (same header color, same font)
  • Body padding/margin for readability
  • Centered headings
  • Links should be styled (a different color, or underlined)
  • Each page should have a footer: "Created by [Your Name] | Digital Skills Course 2024"

Step-by-Step

  1. Create a folder on your Desktop called my-portfolio
  2. Create index.html in Notepad, save inside the folder
  3. Create skills.html in Notepad, save inside the folder
  4. Create contact.html in Notepad, save inside the folder
  5. Open index.html in Chrome
  6. Click on the navigation links — you should be able to move between all 3 pages
  7. Check that all images load, all links work, and the styling looks good

Expected Result

  • 3 connected HTML pages that form a personal portfolio website
  • Navigation works between all pages
  • Consistent styling across all pages
  • Content is personal and genuine (your real skills, real goals, real contact info)
  • Anyone who opens index.html can browse your complete portfolio

Bonus Challenge

  • Add a 4th page: "Projects" — describe 3 things you have built or achieved in this course
  • Add a CSS animation to your name heading (search "CSS text animation" for examples)
  • Add a table of contents on the home page with anchor links to sections
