Part 1: What is Programming?

Explanation

Programming is the art of giving instructions to a computer in a language it understands. A computer is incredibly fast and accurate, but it is also incredibly stupid — it cannot figure anything out on its own. It does exactly what you tell it, nothing more, nothing less.

Think of it like writing a very detailed recipe. When you tell a friend "make tea," they know what you mean because they have common sense. But a computer has zero common sense. You would need to say:

  1. Pick up the kettle
  2. Walk to the sink
  3. Turn on the tap
  4. Fill the kettle with 500ml of water
  5. Turn off the tap
  6. Place the kettle on the stove
  7. Turn on the stove to high
  8. Wait until water boils
  9. Turn off the stove
  10. Place one tea bag in a cup
  11. Pour hot water into the cup
  12. Wait 3 minutes
  13. Remove tea bag
  14. Add 2 spoons of sugar
  15. Stir 5 times

That is programming — breaking every task into tiny, exact steps.

Why Learn Programming?

  • Automation: Make the computer do boring, repetitive tasks for you. Instead of renaming 500 files one by one, write a 5-line program to do it in seconds.
  • Problem Solving: Programming teaches you to think logically and break big problems into small steps — a skill useful in every career.
  • Career Opportunities: Software developer, data analyst, web developer, cybersecurity professional (your instructor's field!), AI/ML engineer — these are the fastest-growing, highest-paying careers globally.
  • Create Things: Build websites, apps, games, tools. Turn your ideas into reality.
  • It is the most in-demand skill worldwide — every industry needs people who can code.

Topic 1: Installing Python

Step-by-Step Guide

Step 1: Download Python
1. Open Chrome and go to python.org
2. Click the big yellow button that says "Download Python 3.x.x" (the latest version)
3. The installer file will download

Step 2: Install Python
1. Open the downloaded file
2. VERY IMPORTANT: At the bottom of the installer, check the box that says "Add Python to PATH" — this is critical, do not skip it
3. Click "Install Now"
4. Wait for installation to complete
5. Click "Close"

Step 3: Verify Installation
1. Open Command Prompt (press Windows key, type "cmd", press Enter)
2. Type: python --version
3. Press Enter
4. You should see something like: Python 3.12.1
5. If you see this, Python is installed correctly

Step 4: Open IDLE (Python's Editor)
1. Press the Windows key
2. Type "IDLE"
3. Click on "IDLE (Python 3.x)"
4. You will see the Python Shell — a window with >>> prompt
5. This is where you can type Python commands and see results immediately

Key Points

  • IDLE stands for Integrated Development and Learning Environment
  • The >>> prompt means Python is ready for your command
  • Type a command and press Enter to run it immediately
  • To write longer programs, go to File > New File in IDLE (this opens a text editor)

Topic 2: Variables — Storing Data

Explanation

A variable is like a labeled box where you store information. You give the box a name, and put something inside it. Later, you can use that name to get the information back.

name = "Rahul"
age = 20
height = 5.8
is_student = True

In the example above:
- name is a box labeled "name" containing the text "Rahul"
- age is a box labeled "age" containing the number 20
- height is a box labeled "height" containing the decimal number 5.8
- is_student is a box labeled "is_student" containing True (yes)

Variable Naming Rules

  • Must start with a letter or underscore (_), not a number
  • Can contain letters, numbers, and underscores
  • No spaces allowed (use underscores: first_name, not first name)
  • Case-sensitive: Name and name are different variables
  • Cannot use Python keywords (like if, for, while, print)

Good and Bad Variable Names

Good Bad Why Bad
student_name 1name Starts with number
total_marks total marks Contains space
age if Reserved keyword
phone_number phone#number Special character

Topic 3: Data Types

Explanation

Every piece of data in Python has a type. Think of it like how in real life, we have different types of information — text, whole numbers, decimal numbers, yes/no.

Type Name Examples Use
str String "Hello", "Rahul", "123" Text (always in quotes)
int Integer 42, -5, 0, 1000 Whole numbers (no decimal)
float Float 3.14, 99.99, -0.5 Decimal numbers
bool Boolean True, False Yes/No values

Important: "123" (in quotes) is a string (text), while 123 (no quotes) is an integer (number). They look similar but behave differently. You cannot do math with "123" because Python sees it as text, not a number.

Topic 4: Print — Displaying Output

Explanation

The print() function tells Python to display something on the screen. It is the most basic and most used function in Python.

print("Hello World!")
print(42)
print(3.14)

Output:

Hello World!
42
3.14

Using Variables with Print

name = "Priya"
age = 22
print("My name is", name)
print("I am", age, "years old")

Output:

My name is Priya
I am 22 years old

f-strings — The Best Way to Insert Variables

The f before the quotes lets you put variables directly inside curly braces {}:

name = "Priya"
age = 22
city = "Mumbai"

print(f"My name is {name}")
print(f"I am {age} years old")
print(f"I live in {city}")
print(f"Next year I will be {age + 1}")

Output:

My name is Priya
I am 22 years old
I live in Mumbai
Next year I will be 23

Topic 5: Input — Getting User Input

Explanation

The input() function lets your program ask the user a question and wait for their answer. Whatever the user types becomes a string.

user_name = input("What is your name? ")
print(f"Hello, {user_name}!")

What happens when you run this:

What is your name? Rahul
Hello, Rahul!

The program pauses at input(), waits for the user to type something and press Enter, then stores their answer in the variable.

Converting Input to Numbers

input() always returns a string. If you need a number for math, you must convert it:

age = int(input("Enter your age: "))       # Convert to whole number
price = float(input("Enter the price: "))   # Convert to decimal number

Common mistake: If you forget to convert and try to do math with a string, you get an error:

# WRONG:
age = input("Enter age: ")   # This is a string "20", not the number 20
next_year = age + 1           # ERROR! Cannot add string + number

# CORRECT:
age = int(input("Enter age: "))  # Convert to integer
next_year = age + 1               # Works! 20 + 1 = 21

Python can do math just like a calculator, but much faster and with much larger numbers.

Topic 7: Conditions — Making Decisions (if/elif/else)

Explanation

Programs need to make decisions — do different things based on different situations. This is done using if, elif (else if), and else statements.

Think of it like this: "IF it is raining, take an umbrella. ELSE IF it is sunny, wear sunglasses. ELSE wear a jacket."

marks = int(input("Enter your marks: "))

if marks >= 90:
    print("Grade: A - Excellent!")
elif marks >= 75:
    print("Grade: B - Very Good")
elif marks >= 60:
    print("Grade: C - Good")
elif marks >= 35:
    print("Grade: D - Pass")
else:
    print("Grade: F - Fail")

Comparison Operators

Operator Meaning Example
== Equal to age == 18
!= Not equal to name != "admin"
> Greater than marks > 90
< Less than price < 100
>= Greater than or equal marks >= 35
<= Less than or equal age <= 65

IMPORTANT: Notice the indentation (4 spaces before print). In Python, indentation is not optional — it tells Python which code belongs inside the if block. Always use 4 spaces (or press Tab in IDLE).

Combining Conditions

age = int(input("Enter age: "))
has_id = input("Do you have ID? (yes/no): ")

if age >= 18 and has_id == "yes":
    print("You can vote!")
elif age >= 18 and has_id == "no":
    print("You are old enough but need an ID card first")
else:
    print("You are too young to vote")
  • and — both conditions must be true
  • or — at least one condition must be true
  • not — reverses a condition

Topic 8: Loops — Repeating Actions

Explanation

Loops let you repeat a block of code multiple times. Instead of writing the same code 100 times, you write it once inside a loop.

for Loop — Repeat a Fixed Number of Times

# Print numbers 0 to 4
for i in range(5):
    print(i)

Output:

0
1
2
3
4

range(5) generates numbers 0, 1, 2, 3, 4 (5 numbers starting from 0).

# Print "Hello" 3 times
for i in range(3):
    print("Hello!")

# Count from 1 to 10
for i in range(1, 11):
    print(i)

# Count by 2s: 2, 4, 6, 8, 10
for i in range(2, 11, 2):
    print(i)

while Loop — Repeat While a Condition is True

count = 5
while count > 0:
    print(f"Countdown: {count}")
    count = count - 1
print("Blast off!")

Output:

Countdown: 5
Countdown: 4
Countdown: 3
Countdown: 2
Countdown: 1
Blast off!

Looping Through a List

fruits = ["apple", "banana", "mango", "guava"]
for fruit in fruits:
    print(f"I like {fruit}")

Output:

I like apple
I like banana
I like mango
I like guava

Topic 9: Lists — Storing Multiple Items

Explanation

A list is a variable that can hold multiple values. Think of it like a shopping list — one list, many items.

colors = ["red", "blue", "green", "yellow"]
numbers = [10, 20, 30, 40, 50]
mixed = ["Rahul", 20, True, 5.8]    # Lists can hold different types

Common List Operations

fruits = ["apple", "banana", "mango"]

# Access by position (starts at 0, not 1!)
print(fruits[0])       # apple
print(fruits[1])       # banana
print(fruits[2])       # mango

# Add an item
fruits.append("guava")
print(fruits)          # ["apple", "banana", "mango", "guava"]

# Remove an item
fruits.remove("banana")
print(fruits)          # ["apple", "mango", "guava"]

# Length of list
print(len(fruits))     # 3

# Check if item exists
if "mango" in fruits:
    print("Yes, mango is in the list!")

Topic 10: Simple Programs — Let Us Build Together

Program 1: Simple Calculator

print("=== Simple Calculator ===")
num1 = float(input("Enter first number: "))
operator = input("Enter operator (+, -, *, /): ")
num2 = float(input("Enter second number: "))

if operator == "+":
    result = num1 + num2
elif operator == "-":
    result = num1 - num2
elif operator == "*":
    result = num1 * num2
elif operator == "/":
    if num2 == 0:
        print("Error: Cannot divide by zero!")
        result = None
    else:
        result = num1 / num2
else:
    print("Invalid operator!")
    result = None

if result is not None:
    print(f"{num1} {operator} {num2} = {result}")

Program 2: Grade Calculator

print("=== Grade Calculator ===")
marks = int(input("Enter marks (0-100): "))

if marks < 0 or marks > 100:

elif marks >= 90:
    print(f"Marks: {marks} — Grade: A (Outstanding)")
elif marks >= 75:
    print(f"Marks: {marks} — Grade: B (Very Good)")
elif marks >= 60:
    print(f"Marks: {marks} — Grade: C (Good)")
elif marks >= 35:
    print(f"Marks: {marks} — Grade: D (Pass)")
else:
    print(f"Marks: {marks} — Grade: F (Fail)")

Program 3: Number Guessing Game

import random

secret = random.randint(1, 20)
attempts = 0

print("=== Number Guessing Game ===")
print("I'm thinking of a number between 1 and 20.")

while True:
    guess = int(input("Your guess: "))
    attempts = attempts + 1

    if guess < secret:
        print("Too low! Try higher.")
    elif guess > secret:
        print("Too high! Try lower.")
    else:
        print(f"Correct! You got it in {attempts} attempts!")
        break

Program 4: Simple To-Do List

print("=== My To-Do List ===")
tasks = []

while True:
    print("\n1. Add task")
    print("2. View tasks")
    print("3. Remove task")
    print("4. Exit")

    choice = input("Choose (1-4): ")

    if choice == "1":
        task = input("Enter task: ")
        tasks.append(task)
        print(f"Added: {task}")
    elif choice == "2":
        if len(tasks) == 0:
            print("No tasks yet!")
        else:
            print("\nYour tasks:")
            for i, task in enumerate(tasks, 1):
                print(f"  {i}. {task}")
    elif choice == "3":
        if len(tasks) == 0:
            print("No tasks to remove!")
        else:
            for i, task in enumerate(tasks, 1):
                print(f"  {i}. {task}")
            num = int(input("Enter task number to remove: "))
            if 1 <= num <= len(tasks):
                removed = tasks.pop(num - 1)
                print(f"Removed: {removed}")
            else:
                print("Invalid number!")
    elif choice == "4":
        print("Goodbye!")
        break
    else:
        print("Invalid choice. Try again.")

Part 3: HTML — Building Web Pages

Topic 11: What is HTML?

Explanation

HTML stands for HyperText Markup Language. It is the language that every website on the internet is built with. When you open any webpage in Chrome, your browser is reading HTML code and displaying it as a formatted page.

HTML is not a programming language (it cannot do calculations or make decisions). It is a markup language — it tells the browser how to structure and display content.

Think of it this way:
- HTML = the skeleton of a building (structure)
- CSS = the paint, tiles, and decoration (styling)
- JavaScript = the electricity, plumbing, elevators (interactivity)

In this module, we will learn HTML (structure) with a touch of CSS (styling).

How to Create an HTML File

You do not need any special software. Just use Notepad:

  1. Open Notepad (press Windows key, type "notepad", press Enter)
  2. Write your HTML code
  3. Click File > Save As
  4. Change "Save as type" to All Files
  5. Name the file with .html extension (example: mypage.html)
  6. Save it to your Desktop
  7. Double-click the saved file — it opens in Chrome!

Topic 12: HTML Structure — The Skeleton

Explanation

Every HTML page follows the same basic structure:

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome to My Website!</h1>
    <p>This is my first webpage. I am learning HTML.</p>
</body>
</html>

What each part does:

Tag Purpose
<!DOCTYPE html> Tells browser this is an HTML5 document
<html> The root element — everything goes inside this
<head> Contains information about the page (title, settings) — not visible on page
<title> The text shown in the browser tab
<body> Everything visible on the page goes here

Topic 13: HTML Tags — Building Blocks

Explanation

HTML uses tags to mark up content. Most tags come in pairs — an opening tag and a closing tag:

<tagname>content goes here</tagname>

The closing tag has a forward slash / before the tag name.

Some tags are self-closing — they do not have content between opening and closing tags:

<br>     <!-- Line break -->
<hr>     <!-- Horizontal line -->
<img>    <!-- Image -->

Essential Tags

Headings — 6 levels, from biggest (h1) to smallest (h6):

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Section Heading</h3>
<h4>Smaller Heading</h4>
<h5>Even Smaller</h5>
<h6>Smallest Heading</h6>

Paragraphs and Text Formatting:

<p>This is a paragraph. It creates a block of text with spacing.</p>

<b>This is bold text</b>
<strong>This is also bold (preferred — means "important")</strong>

<i>This is italic text</i>
<em>This is also italic (preferred — means "emphasized")</em>

<u>This is underlined text</u>

<br>  <!-- This creates a line break (like pressing Enter) -->
<hr>  <!-- This creates a horizontal line across the page -->

Topic 14: Links and Images

Links

Links let you connect to other pages — other websites, or other pages on your own site:

<!-- Link to another website -->
<a href="https://google.com">Go to Google</a>

<!-- Open link in a new tab -->
<a href="https://google.com" target="_blank">Go to Google (new tab)</a>

<!-- Link to another page on your site -->
<a href="skills.html">See My Skills</a>

<!-- Link to an email -->
<a href="mailto:rahul@gmail.com">Email Me</a>

Images

<!-- Image from your computer (same folder as HTML file) -->
<img src="photo.jpg" alt="My Photo" width="300">

<!-- Image from the internet -->
<img src="https://example.com/image.jpg" alt="Description" width="400">
  • src — the source (location) of the image
  • alt — alternative text (shown if image cannot load; also used by screen readers for accessibility)
  • width — width in pixels (height adjusts automatically)

Topic 17: Basic CSS Styling

Explanation

CSS (Cascading Style Sheets) controls how HTML elements look — colors, fonts, sizes, spacing. For now, we will use inline CSS (style directly on elements) to get started.

Inline CSS Syntax

<tagname style="property: value; property: value;">content</tagname>

Common CSS Properties

<!-- Text color -->
<p style="color: blue;">This text is blue</p>
<p style="color: #FF5733;">This text is orange (hex color)</p>

<!-- Font size -->
<p style="font-size: 24px;">This text is larger</p>

<!-- Background color -->
<p style="background-color: yellow;">Yellow background</p>

<!-- Text alignment -->
<p style="text-align: center;">This text is centered</p>

<!-- Font family -->
<p style="font-family: Arial, sans-serif;">Arial font</p>

<!-- Border -->
<p style="border: 2px solid black; padding: 10px;">Text with a border</p>

<!-- Multiple styles -->
<h1 style="color: white; background-color: darkblue; text-align: center; padding: 20px;">
    Styled Heading
</h1>

Styling a Full Page Example

<!DOCTYPE html>
<html>
<head>
    <title>Styled Page</title>
</head>
<body style="font-family: Arial, sans-serif; margin: 40px; background-color: #f0f0f0;">

    <h1 style="color: darkblue; text-align: center;">My Styled Page</h1>
    <hr>

    <p style="font-size: 18px; line-height: 1.6;">
        This paragraph has larger text and more spacing between lines,
        making it easier to read.
    </p>

    <table style="width: 100%; border-collapse: collapse;">
        <tr style="background-color: darkblue; color: white;">
            <th style="padding: 10px; border: 1px solid #ddd;">Skill</th>
            <th style="padding: 10px; border: 1px solid #ddd;">Level</th>
        </tr>
        <tr>
            <td style="padding: 10px; border: 1px solid #ddd;">Python</td>
            <td style="padding: 10px; border: 1px solid #ddd;">Beginner</td>
        </tr>
        <tr style="background-color: #f9f9f9;">

            <td style="padding: 10px; border: 1px solid #ddd;">Beginner</td>

</body>
</html>
