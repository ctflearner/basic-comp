Practice Task 1: Copy and Move Files

Objective: Practise creating, copying, and moving files to understand the difference between the two operations.
Difficulty: Beginner
Time: 20 minutes

Instructions

  1. Open File Explorer (Win+E) and go to Documents.
  2. Create a folder called File Practice.
  3. Go inside "File Practice."
  4. Create 10 text files of different names:
    a. Right-click, New, Text Document. Name it Note1.txt. Press Enter.
    b. Open Note1.txt, type "This is note number one," save (Ctrl+S), and close.
    c. Repeat for Note2.txt through Note10.txt, typing a different sentence in each.
  5. Create two subfolders inside "File Practice":
    a. Copied Files
    b. Moved Files
  6. Copy 5 files:
    a. Hold Ctrl and click on Note1.txt, Note2.txt, Note3.txt, Note4.txt, and Note5.txt (all five should be highlighted).
    b. Press Ctrl+C (Copy).
    c. Double-click the "Copied Files" folder to go inside.
    d. Press Ctrl+V (Paste).
    e. The 5 files appear here.
    f. Click the Back arrow to go back to "File Practice."
    g. Verify: Note1-5 are STILL HERE in "File Practice" (because you copied, not moved).
  7. Move the other 5 files:
    a. Hold Ctrl and click on Note6.txt, Note7.txt, Note8.txt, Note9.txt, and Note10.txt.
    b. Press Ctrl+X (Cut). Notice the file icons become slightly faded.
    c. Double-click the "Moved Files" folder.
    d. Press Ctrl+V (Paste).
    e. The 5 files appear here.
    f. Click the Back arrow.
    g. Verify: Note6-10 are GONE from "File Practice" (because you moved them).

Expected Result

  • "File Practice" folder contains: Note1-5 (originals), plus the two subfolders.
  • "Copied Files" folder contains: copies of Note1-5.
  • "Moved Files" folder contains: Note6-10 (moved from the parent folder).
  • You understand that Copy keeps the original, and Move removes it.

Bonus Challenge

Use Ctrl+Z (Undo) immediately after moving the files. What happens? The files return to their original location. Try it and observe.

Practice Task 2: USB Drive Operations

Objective: Practise transferring files to and from a USB drive with proper safe ejection.
Difficulty: Beginner
Time: 15 minutes

Instructions

You will need a USB drive (pendrive/flash drive) for this task.

  1. Plug in the USB drive to a USB port on your computer.
  2. Wait for it to be recognised (you may hear a sound or see a notification).
  3. Open File Explorer (Win+E).
  4. Click "This PC" in the left sidebar.
  5. Find your USB drive in the list of drives. Note its letter (e.g., E: or F:) and name.
  6. Double-click to open the USB drive.
  7. Create a folder on the USB drive:
    a. Right-click on empty space, New, Folder.
    b. Name it Backup Test.
    c. Go inside the folder.
  8. Copy 3 files from your computer to the USB drive:
    a. Open a second File Explorer window (press Win+E again).
    b. In the new window, navigate to Documents (or wherever you have files).
    c. Select 3 files (hold Ctrl and click each one).
    d. Press Ctrl+C (Copy).
    e. Switch to the first File Explorer window (the USB drive's "Backup Test" folder).
    f. Press Ctrl+V (Paste).
    g. Wait for the copy to complete.
  9. Verify the files: Open each file on the USB drive to make sure they copied correctly.
  10. Safely eject the USB drive:
    a. Look at the bottom-right corner of your screen (system tray).
    b. Click the small up arrow to show hidden icons.
    c. Find and click the USB icon (looks like a plug or drive).
    d. Click "Eject [your USB drive name]."
    e. Wait for the message: "Safe to Remove Hardware."
    f. Now gently pull the USB drive out of the port.
  11. Plug the USB drive back in and verify your files are still there and undamaged.

Expected Result

You have a "Backup Test" folder on your USB drive containing 3 files from your computer. You safely ejected and reconnected the drive, and all files are intact.

Bonus Challenge

Copy files FROM the USB drive back to a different folder on your computer. This is how you would restore files from a backup.

Practice Task 3: File Extensions

Objective: Enable file extensions and identify the types of files on your computer.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Turn on file extensions (if not already on):
    a. Open File Explorer (Win+E).
    b. Click the "View" menu at the top.
    c. Hover over "Show."
    d. Click "File name extensions" so a checkmark appears next to it.
    e. Now all files show their extensions (e.g., "Report.pdf" instead of just "Report").

  2. Identify file types:
    a. Navigate to your Downloads folder.
    b. Look at the files there. On paper or in Notepad, create a list of 10 different files and their extensions.
    c. For each file, write:

    • File name (with extension)
    • What type of file it is (image, document, video, program, etc.)
    • What program would open it

Example:
1. Report.pdf - Document - Adobe Reader or Edge 2. photo.jpg - Image - Photos app 3. setup.exe - Program - (Installer - be careful)

  1. If Downloads does not have 10 files, also check Documents and Pictures.

  2. Check file properties:
    a. Right-click on any file.
    b. Click "Properties."
    c. Write down the file's: size, type, creation date, and which program opens it.
    d. Click OK to close.

Expected Result

File extensions are visible on your computer. You have a written list of 10 files with their extensions, types, and associated programs. You can identify what kind of file something is by looking at its extension.

Bonus Challenge

Find out how much total storage your different file types are using. In File Explorer, search for *.jpg in This PC, then sort by size. Do the same for *.pdf and *.mp4. Which file type takes up the most space?

Practice Task 4: Search for Files

Objective: Use Windows Search and File Explorer search to find specific files quickly.
Difficulty: Beginner
Time: 15 minutes

Instructions

  1. Windows Search (taskbar):
    a. Click the Search icon on the taskbar (or press Win+S).
    b. Type the name of a file you know exists (for example, a file you created in earlier tasks).
    c. Look at the results. Click "Open file location" under the file to see where it is stored.
    d. Write down the file's full path.

  2. File Explorer search (within a specific folder):
    a. Open File Explorer (Win+E).
    b. Click on "This PC" (to search the entire computer).
    c. Click the search box in the top-right corner.
    d. Type *.pdf and press Enter.
    e. Wait for results. Count how many PDF files you have on your computer. Write down the number.

  3. Search for images:
    a. Clear the search box and type *.jpg
    b. Count the number of JPG images on your computer. Write it down.

  4. Search for large files:
    a. Navigate to "This PC" again.
    b. In the search box, type size:large (this finds files larger than 128 MB).
    c. Look at the results. These large files might be videos, games, or programs.
    d. Write down the 3 largest files and their sizes.

  5. Search within a specific folder:
    a. Navigate to your Documents folder.
    b. In the search box, type the name of a file you created in an earlier module.
    c. The search only looks inside Documents and its subfolders.

Expected Result

You found files using both Windows Search and File Explorer search. You know how many PDFs and JPGs are on your computer, and you identified your 3 largest files. You can now quickly find any file on your computer.

Bonus Challenge

Try these advanced searches in File Explorer:
- *.mp4 to find all videos
- datemodified:this week to find files you changed recently
- Combine them: *.docx datemodified:this month to find Word docs from this month

Practice Task 5: Backup Your Important Files

Objective: Create a real backup of your most important files on a USB drive or cloud storage.
Difficulty: Intermediate
Time: 30 minutes

Instructions

  1. Identify your 10 most important files:
    Open Notepad and create a list. Think about:
  2. Documents you cannot recreate (ID scans, certificates, contracts)
  3. Work files that took hours to create
  4. Irreplaceable photos
  5. Financial records

Write down each file's name and location. Example:
1. CV.docx - Documents/Work/CVs 2. ID Scan.pdf - Documents/Personal/ID Documents 3. Family Photo.jpg - Pictures/Family ...

  1. Choose your backup method:

Option A: USB Drive Backup
a. Plug in a USB drive.
b. Create a folder on the USB drive called "Backup - [today's date]".
c. Copy each of your 10 important files to this folder.
d. Verify each file opens correctly from the USB drive.
e. Safely eject the USB drive.
f. Store the USB drive in a different physical location from your computer (e.g., a drawer in another room).

Option B: Cloud Backup (OneDrive or Google Drive)
a. Open your web browser.
b. Go to drive.google.com (for Google Drive) or onedrive.com (for OneDrive).
c. Sign in with your account (create one if needed).
d. Click "New" or the upload button.
e. Upload each of your 10 important files.
f. Verify each file by clicking on it in the cloud to make sure it uploaded correctly.

  1. Create a backup log:
    Open Notepad and save this in Documents as "Backup Log.txt":

```
BACKUP LOG
==========
Date: [today's date]
Backup location: [USB drive name / Google Drive / OneDrive]

Files backed up:
1. [filename] - OK
2. [filename] - OK
3. [filename] - OK
...

Next backup date: [one month from now]
```

  1. Set a reminder on your phone to repeat this backup in one month.

Expected Result

Your 10 most important files are backed up to either a USB drive or cloud storage. You have a backup log documenting what was backed up and when. You have a reminder to do this monthly.

Bonus Challenge

Do BOTH backup methods -- USB and cloud. This follows the 3-2-1 rule: your computer has the originals (1), the USB drive has a copy (2), and the cloud has another copy (3), stored offsite.

Module Assessment

Answer these questions on paper or in a text file.

  1. Explain the file system hierarchy using the building analogy (drive, folder, subfolder, file).
  2. What is the difference between copying and moving a file? Which keyboard shortcuts do you use for each?
  3. What happens when you press Delete on a file? What happens when you press Shift+Delete?
  4. What is a file extension? Give 5 examples with what each one means.
  5. Why should you always show file extensions on your computer?
  6. Describe the correct steps to safely remove a USB drive from your computer.
  7. What is the 3-2-1 backup rule?
  8. How do you search for all PDF files on your computer using File Explorer?
  9. What is the danger of opening an unknown .exe file?
  10. Name two places you can store backups and one advantage of each.

Scoring: Each question is worth 1 point. 8 or more correct = you are ready for Module 6. Below 8 = review the topics you missed.

Real-Life Mini Project: "Digital Life Organiser"

Objective: Apply everything from this module to organise and protect your digital life.
Time: 45 minutes

Instructions

This project ties together everything you learned in Modules 1 through 5.

Part 1: Organise Your Files (15 minutes)

  1. Open File Explorer and navigate to your Documents folder.
  2. Make sure you have a folder structure like this (create any folders that are missing):
    Documents/ Personal/ Work/ Education/ Digital Skills Course/
  3. Go through any files in the root of Documents and move them into the appropriate subfolder.
  4. Go to your Downloads folder. Sort and organise loose files into subfolders (Images, Documents, Videos, Software) or delete files you no longer need.

Part 2: Enable Security Settings (10 minutes)

  1. Turn on file extensions (View, Show, File name extensions).
  2. Lock your computer (Win+L) and unlock it. Confirm it works.
  3. Open Windows Security and verify your antivirus is active.

Part 3: Create Your Backup (15 minutes)

  1. Identify your 5 most important files.
  2. Back them up to a USB drive OR upload them to OneDrive/Google Drive.
  3. Verify the backup works by opening each file from the backup location.

Part 4: Document Everything (5 minutes)

  1. Open Notepad and create a file called "My Digital Setup.txt" in Documents:
MY DIGITAL SETUP
================
Date: [today's date]

Computer Specs:
- Processor: [from Module 1 spec sheet]
- RAM: ____
- Storage: ____ total, ____ free

Folder Structure:
- Documents: Personal, Work, Education
- Downloads: Organised into Images, Documents, Videos, Software
- Pictures: Screenshots folder created

Security:
- File extensions: Visible
- Antivirus: Active
- Screen lock: Working (Win+L)

Backup:
- Location: [USB drive / Cloud]
- Last backup: [today's date]
- Files backed up: [list of 5 files]

Next Actions:
- Monthly backup reminder set: [Yes/No]
- Monthly maintenance checklist: [In Documents / Not yet]
  1. Save this file. It is your digital reference sheet.

Expected Result

Your computer is organised, secure, and backed up. You have a reference document that records your setup. You can find any file quickly, back up important data, and use your computer confidently. You are now ready to learn about the internet in Module 6.
